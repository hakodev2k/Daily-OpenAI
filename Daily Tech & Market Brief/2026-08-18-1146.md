## 2. AI and Technology

### Agent reliability and governance

**Confirmed facts**
- AI adoption is moving toward multi-step agents using tools, APIs, browsers, databases, and code execution.
- Reliability challenges include hallucination, permission boundaries, cost control, and evaluation.

**Analysis**
- The next competitive advantage is likely not only better models but better agent systems.

**Developer impact**
- Build reusable components:
  - tool permission layer
  - execution audit logs
  - evaluation pipelines
  - retry and recovery strategies

**Risks**
- Autonomous actions without approval controls can create security incidents.
