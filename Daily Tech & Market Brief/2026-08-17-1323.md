## 3. .NET and Software Development

### 3.1 Kiểm tra servicing/security patch level của .NET 8/9/10

**Action level:** **Immediate action** nếu production chưa ở latest supported patch.

**Confirmed facts**
- Microsoft July 2026 servicing update đã vá nhiều lỗ hổng trên .NET 8, .NET 9 và .NET 10, bao gồm các CVE thuộc nhóm .NET Security Vulnerability.
- Security fixes được phát hành qua servicing updates chứ không yêu cầu đổi major version.

**Recommended actions**
1. Chạy `dotnet --info` trên host/container thật.
2. Kiểm tra base image trong Dockerfile, ví dụ `mcr.microsoft.com/dotnet/aspnet:*`.
3. Rebuild image để lấy patched runtime nếu đang dùng floating tag.
4. Kiểm tra self-contained deployments vì chúng không tự nhận runtime patch từ host.
5. Chạy smoke/regression tests sau khi patch.

**Nguồn:** [.NET July 2026 servicing updates](https://devblogs.microsoft.com/dotnet/dotnet-and-dotnet-framework-july-2026-servicing-updates/)
