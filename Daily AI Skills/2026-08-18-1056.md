## 3. Prompt, Skills, Rules, and Context Engineering

### Problem
Prompt hội thoại không đủ để duy trì consistency trong dự án dài hạn.

### Improvement
Xây context layer:

```text
.ai/
 ├── architecture.md
 ├── coding-rules.md
 ├── testing.md
 ├── security.md
 └── decisions/
```

### Benefit
- Giảm context loss.
- Chuẩn hóa AI behavior.
- Hỗ trợ onboarding.

### Risks
- Documentation outdated gây sai lệch.
- Rule conflict giữa tools.

## 4. Agent, Workflow, and Loop Engineering

### Recommended loop

```text
Requirement
 ↓
Plan
 ↓
Implement
 ↓
Run deterministic checks
 ↓
Review
 ↓
Accept / Retry / Stop
```

### Key controls
- Retry limit.
- Scope boundary.
- Confidence report.
- Human approval cho architecture/security changes.

### Suitable use cases
- .NET refactoring.
- EF Core migration.
- QA automation.
- Architecture review.
