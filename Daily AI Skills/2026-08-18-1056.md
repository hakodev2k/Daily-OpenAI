# AI Skills & Agent Engineering Briefing

Ngày: 2026-08-18 (UTC+7)

## 1. Executive Summary

### 1. Agentic coding tiếp tục chuyển từ chat hỗ trợ sang workflow có kiểm chứng
- **Confirmed facts:** Các nền tảng AI coding hiện tập trung vào agent có khả năng đọc repository, lập kế hoạch, sửa code và chạy công cụ thay vì chỉ sinh đoạn code. OpenAI Codex, GitHub Copilot coding agent và các IDE agent đều hướng tới workflow này.
- **Affected skill:** Agent workflow engineering.
- **Analysis:** Giá trị lớn nhất không nằm ở việc tạo code nhanh hơn mà ở khả năng thiết kế vòng lặp plan → execute → verify.
- **Recommendation:** Xây dựng workflow bắt buộc agent tạo plan, thay đổi nhỏ, chạy test và báo cáo confidence.
- **Uncertainty:** Hiệu quả phụ thuộc mạnh vào repository context và validation.
- **Priority:** High.

### 2. Repository instructions trở thành lớp context quan trọng nhất
- **Confirmed facts:** Cursor Rules, Claude Code instructions, Copilot repository guidance và các file hướng dẫn AI trong repo đang được sử dụng để định nghĩa coding convention.
- **Affected skill:** Context engineering.
- **Analysis:** Prompt tốt ở cấp hội thoại không đủ cho dự án dài hạn; instruction-as-code giúp AI hoạt động nhất quán.
- **Recommendation:** Duy trì `.ai/`, `AGENTS.md`, rules cho architecture, testing, security.
- **Uncertainty:** Chưa có chuẩn chung giữa các công cụ.
- **Priority:** High.

### 3. MCP trở thành lớp tích hợp quan trọng cho AI agent
- **Confirmed facts:** Model Context Protocol cung cấp cơ chế chuẩn hóa kết nối agent với tools, data sources và external systems. https://modelcontextprotocol.io/
- **Affected skill:** Tool integration.
- **Analysis:** MCP có thể thay thế nhiều integration riêng lẻ khi xây dựng internal AI agents.
- **Recommendation:** Test MCP với database read-only, GitHub, documentation search.
- **Uncertainty:** Security model và enterprise adoption vẫn đang phát triển.
- **Priority:** Medium.

### 4. Evaluation cho agent quan trọng hơn benchmark model đơn thuần
- **Confirmed facts:** Agent cần đánh giá bằng task completion, regression tests, tool usage và failure cases.
- **Affected skill:** AI reliability engineering.
- **Analysis:** Một agent mạnh nhưng không kiểm soát được permission có thể gây rủi ro production.
- **Recommendation:** Xây deterministic validation trước khi tăng quyền agent.
- **Uncertainty:** Chưa có chuẩn evaluation thống nhất.
- **Priority:** High.

## 3. Prompt, Skills, Rules, and Context Engineering

### Vấn đề
Agent thường mất context hoặc tạo giải pháp không phù hợp architecture.

### Improvement
Tạo repository knowledge layer:

```
.ai/
 ├── architecture.md
 ├── coding-style.md
 ├── testing.md
 ├── security.md
 └── decisions/
```

### Vì sao hiệu quả
- Giảm dependency vào memory của model.
- Tạo nguồn sự thật ổn định.
- Hỗ trợ onboarding developer mới.

### Use cases
- .NET Clean Architecture.
- DDD boundaries.
- API conventions.
- Database migration rules.

### Risks
- Documentation lỗi sẽ khiến agent lặp lại sai.

## 4. Agent, Workflow, and Loop Engineering

### Kỹ thuật: Plan-Execute-Review-Verify Loop

**Problem:** Agent sửa code nhưng không kiểm tra tác động.

**Technique:**

```
Requirement
 ↓
Plan
 ↓
Implementation
 ↓
Test
 ↓
Review
 ↓
Decision
```

**Expected benefit**
- Giảm hallucinated changes.
- Tăng khả năng debug.

**Failure risks**
- Loop vô hạn.
- Token cost tăng.
- Agent sửa quá mức.

**Recommendation:** Thêm stop conditions:
- Không thay đổi ngoài scope.
- Không retry quá N lần.
- Yêu cầu human approval khi đổi architecture.
