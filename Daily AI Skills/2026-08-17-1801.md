# AI Skills & Agent Engineering Briefing

## 1. Executive Summary

### Agent verification cần đi cùng evidence channel
- Confirmed facts: Agent systems đang bổ sung context từ tools, images và artifacts vào verification flows.
- Analysis: Executor và verifier có cùng evidence sẽ giảm asymmetric context errors.
- Recommendation: Thiết kế EvidenceEnvelope gồm source, timestamp, artifact và validation status.
- Priority: Critical.

### Context engineering chuyển sang quản lý budget
- Confirmed facts: Skills, rules và retrieved context đều cạnh tranh token budget.
- Analysis: Thêm nhiều instructions không đồng nghĩa agent tốt hơn.
- Recommendation: Đo skill selection accuracy, latency và task success.
- Priority: High.

### Least privilege là nền tảng cho agent production
- Confirmed facts: Tool permission, sandbox và approval boundary là các thành phần quan trọng của agent safety.
- Analysis: Prompt không thể thay thế runtime security.
- Recommendation: Áp dụng permission intersection: global, workspace, task, human approval.
- Priority: Critical.

## 2. Tool and Platform Updates

### Coding agents
- Confirmed facts: Các nền tảng như Codex, Claude Code, GitHub Copilot tiếp tục mở rộng từ autocomplete sang task execution.
- Impact: Cần đánh giá workflow thay vì chỉ đánh giá code output.
- Action: Test.

### MCP integrations
- Confirmed facts: MCP cung cấp mô hình kết nối model với tools và data sources.
- Impact: Phù hợp cho GitHub, database, documentation assistant.
- Action: Investigate.

## 3. Prompt, Skills, Rules, and Context Engineering

Problem: Agent thiếu kiến thức dự án ổn định.

Improvement:
- Repository rules.
- Architecture decisions.
- Coding conventions.
- Validation checklist.

Use cases:
- .NET architecture review.
- Code review agent.
- QA agent.

Risks:
- Context overload.
- Outdated instructions.

## 4. Agent, Workflow, and Loop Engineering

Recommended loop:

Plan → Execute → Verify → Repair → Re-test

Benefits:
- Giảm hallucinated fixes.
- Tăng reproducibility.

Risks:
- Infinite retry.
- Cost escalation.

Use cases:
- Refactoring.
- Migration.
- Automated testing.
