# AI Skills & Agent Engineering Briefing — 2026-08-17 18:01 (UTC+7)

## 1. Executive Summary

### Agent verification cần chia sẻ evidence với execution context
- Confirmed facts: Agent workflows ngày càng dùng tool outputs, artifacts và multimodal evidence trong quá trình kiểm tra.
- Analysis: Nếu executor thấy context mà verifier không thấy, hệ thống dễ có asymmetric-context errors.
- Recommendation: Thiết kế `EvidenceEnvelope` gồm source, timestamp, artifact, confidence và validation status.
- Priority: Critical.

### Context engineering chuyển từ prompt dài sang budget management
- Confirmed facts: Rules, skills, retrieved documents và conversation history đều tiêu thụ context window.
- Analysis: Tăng instruction không đồng nghĩa tăng chất lượng agent.
- Recommendation: Theo dõi token usage, skill selection accuracy, latency và task success.
- Priority: High.

### Runtime permission quan trọng hơn prompt security
- Confirmed facts: Sandbox, tool permission, approval flow và secret handling là các lớp bảo vệ agent.
- Analysis: Prompt chỉ định hướng hành vi, không thay thế security boundary.
- Recommendation: Áp dụng permission model: global → workspace → task → human approval.
- Priority: Critical.

- ADR documents.

Suitable use cases:

- QA agent.

Risks:

- Outdated rules.
- Conflicting instructions.

## 4. Agent, Workflow, and Loop Engineering

Recommended loop:

Plan → Execute → Review → Verify → Fix → Re-test

Expected benefits:
- Giảm hallucinated changes.
- Tăng reproducibility.
- Dễ debug failure.

Failure risks:
- Infinite retry loops.
- Cost escalation.
- Wrong verification criteria.

Suitable use cases:
- Refactoring.
- Migration.
- Automated testing.
- Architecture analysis.
