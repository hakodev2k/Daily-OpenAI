## 3. Prompt, Skills, Rules, and Context Engineering

### Vấn đề
Prompt đơn lẻ khó duy trì khi dự án lớn.

### Improvement
Chuyển sang repository-level context:
- Architecture rules.
- Coding conventions.
- Testing rules.
- Domain glossary.
- Deployment constraints.

### Why it may work
Agent cần context ổn định hơn là instruction lặp lại.

### Use cases
- .NET Clean Architecture.
- API design review.
- Database migration.
- Code review.

### Limitations
Context quá dài làm giảm signal-to-noise.

### Risk
Rules sai có thể khiến agent lặp lại lỗi kiến trúc.

## 4. Agent, Workflow, and Loop Engineering

### Problem
Agent dễ rơi vào vòng lặp sửa lỗi không kết thúc.

### Technique
Thiết kế loop:

1. Analyze.
2. Create plan.
3. Implement smallest change.
4. Run deterministic validation.
5. Review failure.
6. Stop nếu confidence thấp.

### Expected benefit
- Giảm hallucination.
- Dễ debug.
- Dễ audit.

### Failure risks
- Agent tối ưu theo test nhưng phá business logic.
- Retry vô hạn gây tăng cost.

### Suitable use cases
- Automated bug fixing.
- Migration.
- Refactoring.
- Test generation.

## 5. Hooks and Integrations

| Integration | Benefit | Risk | Difficulty |
|-|-|-|-|
| MCP + Database | Agent hiểu schema thật | Data exposure | Moderate |
| GitHub Actions | Automated review/test loop | Permission abuse | Moderate |
| Teams/Slack agent | Async task delegation | Sensitive data leakage | Advanced |
| Browser automation | UI testing | Fragile selectors | Experimental |

Recommendation:
- Dùng least privilege.
- Log mọi tool call quan trọng.
- Không cho agent production access mặc định.
