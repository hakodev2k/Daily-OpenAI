# AI Skills & Agent Engineering Briefing

**Ngày:** 18/08/2026 12:05 (UTC+7)

## 1. Executive Summary

### 1. Agent engineering đang chuyển trọng tâm từ prompting sang workflow control
- **Confirmed facts:** Coding agents hiện hỗ trợ repository context, tool execution, IDE/CLI integration và các workflow nhiều bước.
- **Affected skill:** Agent workflow engineering.
- **Analysis:** Chất lượng đầu ra phụ thuộc nhiều vào loop plan → execute → verify hơn là prompt dài.
- **Recommendation:** Thiết kế agent có checkpoint, validation và human approval.
- **Priority:** Critical.

### 2. Repository instructions trở thành lớp context quan trọng
- **Confirmed facts:** Các AI coding tools hỗ trợ hướng dẫn dự án dạng rules/instructions.
- **Affected skill:** Context engineering.
- **Analysis:** Context ổn định giúp giảm việc lặp lại yêu cầu.
- **Recommendation:** Duy trì architecture rules, coding conventions, testing rules.
- **Priority:** High.

### 3. AI agent cần permission boundary rõ ràng
- **Confirmed facts:** Các coding agent ngày càng tích hợp nhiều tool như filesystem, terminal, Git và external services.
- **Affected skill:** Security and agent governance.
- **Analysis:** Quyền truy cập là yếu tố quyết định khả năng đưa agent vào workflow thật.
- **Recommendation:** Áp dụng least privilege.
- **Priority:** High.

## 3. Prompt, Skills, Rules, and Context Engineering

### Problem
Prompt riêng lẻ khó mở rộng cho dự án dài hạn.

### Improvement
Xây context package:
- Architecture principles.
- Domain knowledge.
- Database rules.
- API conventions.
- Testing strategy.
- Deployment constraints.

### Analysis
Agent cần "operating manual" giống thành viên team mới.

### Limitations
Context quá lớn làm giảm khả năng tập trung.

### Risk
Rules lỗi có thể lan truyền lỗi thiết kế.

## 4. Agent, Workflow, and Loop Engineering

### Problem
Agent dễ retry vô hạn hoặc sửa sai hướng.

### Technique
Loop chuẩn:

1. Understand requirement.
2. Identify assumptions.
3. Create plan.
4. Implement.
5. Validate with deterministic checks.
6. Ask for approval at risky points.

### Expected benefit
- Giảm regression.
- Tăng khả năng audit.
- Dễ debug agent behavior.

### Failure risks
- Over-automation.
- Test passing nhưng business logic sai.
- Cost tăng do retry không giới hạn.

## 5. Hooks and Integrations

| Integration | Benefit | Risk | Difficulty |
|-|-|-|-|
| MCP + Database metadata | Agent hiểu schema | Data exposure | Moderate |
| GitHub Actions | Automated validation | Token abuse | Moderate |
| Teams/Slack | Async collaboration | Information leakage | Advanced |
| Browser automation | UI testing | Fragility | Experimental |

Recommendation:
- Log tool usage.
- Separate read/write permissions.
- Require approval before deployment.
