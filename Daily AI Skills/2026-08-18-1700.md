# AI Skills & Agent Engineering Briefing

Ngày: 2026-08-18 (UTC+7)

## 1. Executive Summary

### 1. Agent workflow engineering trở thành kỹ năng cốt lõi
- **Confirmed facts:** AI coding tools đang chuyển từ code completion sang agent workflow có khả năng đọc repository, sử dụng tools, tạo thay đổi và phối hợp kiểm thử. (OpenAI Codex: https://openai.com/codex/ ; GitHub Copilot docs: https://docs.github.com/en/copilot)
- **Analysis:** Giá trị thực tế phụ thuộc vào workflow kiểm chứng hơn là khả năng sinh code.
- **Recommendation:** Chuẩn hóa loop Plan → Execute → Test → Review → Verify.
- **Uncertainty:** Hiệu quả thay đổi theo repository context và mức độ automation.
- **Priority:** High.

### 2. Repository context engineering tiếp tục là nền tảng
- **Confirmed facts:** Các công cụ AI hỗ trợ rules/instructions trong repository để duy trì coding convention và kiến trúc.
- **Analysis:** Context ổn định giúp giảm output không nhất quán giữa các session.
- **Recommendation:** Duy trì AGENTS.md, architecture rules, testing rules, security rules.
- **Priority:** High.

### 3. MCP mở rộng khả năng kết nối agent với hệ thống thật
- **Confirmed facts:** Model Context Protocol cung cấp chuẩn kết nối model với tools và data sources. https://modelcontextprotocol.io/
- **Analysis:** MCP phù hợp cho developer agent, research agent và enterprise automation.
- **Recommendation:** Ưu tiên integration read-only trước.
- **Priority:** Medium.

## 2. Tool and Platform Updates

### AI Coding Agents
**Confirmed facts:** OpenAI Codex, GitHub Copilot và IDE AI agents đang tập trung vào repository-level tasks.

**Practical impact:** Developer cần chuyển từ viết prompt sinh code sang thiết kế task, constraint và validation.

**Recommendation:** Test workflow:
1. Agent đọc issue.
2. Tạo implementation plan.
3. Sửa code.
4. Chạy test.
5. Human review.

## 4. Agent, Workflow, and Loop Engineering

**Technique:** Plan-Execute-Review-Verify.

**Expected benefit:**
- Giảm thay đổi ngoài scope.
- Tăng khả năng trace decision.
- Hỗ trợ long-running tasks.

**Failure risks:**
- Infinite retry loop.
- Token cost tăng.
- Agent tự mở rộng scope.

**Recommendation:** Thiết lập:
- Maximum retries.
- Stop conditions.
- Human approval cho architecture/security changes.
