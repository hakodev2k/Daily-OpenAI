## 1. Executive Summary

### 1. Guardian v2 defaults chuyển một phần safety/review behavior sang **model-owned capability metadata**

- **One-sentence summary:** Codex `main` thêm `guardian_v2` defaults vào model catalog cho classifier prompt, review threshold, reasoning effort, transcript selection/limits và action/compaction token limits; local config vẫn override catalog. [Codex #38990, 17/08/2026](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)
- **Affected skill area:** Agent safety, review agents, capability discovery, configuration layering, evaluation reproducibility.
- **Why it matters:** Cùng một workflow nhưng khác model có thể cần review threshold, transcript selection hoặc reasoning effort khác nhau; hard-code một bộ defaults toàn cục dễ làm behavior sai lệch hoặc khó tuning.
- **Practical implication:** Agent runtime nên resolve behavior từ một **capability/config stack** thay vì chỉ prompt + local config: model defaults → environment/workspace policy → explicit local override → per-run parameters.
- **Priority:** **Critical** cho agent platform/framework; **High** cho coding agent cá nhân.
- **Confirmed facts:** Commit thêm optional `guardian_v2` model-message defaults cho classifier instructions, review-threshold basis points, reasoning effort, transcript sources và transcript limits, action-token limit, classifier-instruction-token limit và parent-compaction-token limit; sampling áp dụng model defaults nhưng giữ local `[features.guardianv2]` có precedence. Tests cover serialization, model overrides và local-override precedence. [Source](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)
- **Analysis:** Đây là signal rõ rằng một agent runtime ngày càng cần **model capability registry** chứ không thể coi model name chỉ là string để gửi request. Safety/review configuration có thể phụ thuộc model family và được phân phối cùng model metadata.
- **Recommendation:** Trong agent framework riêng, tạo `ModelCapabilityProfile` với `context`, `tooling`, `permissions`, `review`, `multimodal`, `tokenBudgets`, `transport`; mỗi run phải lưu resolved profile/version vào telemetry để regression dễ giải thích.
- **Uncertainty:** Đây là Codex source-level design; chưa có evidence public rằng mọi hosted Codex session hoặc stable 0.147.0 dùng mechanism này.

### 2. Config precedence trở thành first-class correctness concern

- **One-sentence summary:** Codex mới xác định local Guardian v2 config override model-catalog defaults, và model override phải preserve phần catalog config mới. [Codex #38990](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)
- **Affected skill area:** Rules, reusable config, model routing, policy resolution, debugging.
- **Why it matters:** Khi agent có global defaults, model defaults, repo rules, environment restrictions và per-task config, bug thường không nằm ở từng file mà nằm ở **precedence order**.
- **Practical implication:** Mỗi effective setting nên có provenance: `value`, `source`, `sourceVersion`, `resolvedAt`, `overriddenBy`.
- **Priority:** **High**.
- **Confirmed facts:** Commit dùng model defaults chỉ khi local override tương ứng chưa được set; local Guardian config được giữ riêng để re-resolve khi model context thay đổi. [Source](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)
- **Analysis:** Config resolution nên được xem như một deterministic function có test matrix, không phải logic rải rác trong prompt/runtime.
- **Recommendation:** Thêm command/debug view kiểu `agent config explain` để hiển thị final effective config và nguồn của từng value.
- **Uncertainty:** Không có benchmark public cho chi phí runtime hoặc độ phức tạp vận hành của model-owned defaults ở quy mô lớn.

### 3. Guardian v2 đã bắt đầu nhận **visual evidence** từ transcript và tool outputs

- **One-sentence summary:** Codex `main` có opt-in `features.guardianv2.transcript.include_images`, lấy ảnh từ user/assistant messages và configured tool outputs, giới hạn tối đa 4 ảnh gần nhất và 8 MiB tổng. [Codex #38987, 17/08/2026](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e)
- **Affected skill area:** Multimodal QA, browser agents, safety/verifier pipelines, evidence collection.
- **Why it matters:** Browser/UI agents thường ra quyết định từ screenshot; verifier chỉ thấy text sẽ có asymmetric context so với executor.
- **Practical implication:** Screenshot nên là first-class evidence với provenance, timestamp, hash, redaction metadata và bounded retention.
- **Priority:** **Critical** cho browser/UI automation; **High** cho coding agents có image-bearing tool outputs.
- **Confirmed facts:** Setting mặc định `false`; ảnh có thể đến từ user, assistant và tool outputs; bounded queue tối đa 4 ảnh, 8 MiB; detail hints bị bỏ trước sampling. [Source](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e)
- **Analysis:** Verification channel nên có cùng evidence classes với execution channel; đây là pattern quan trọng hơn chính feature Guardian.
- **Recommendation:** Chuẩn hóa `EvidenceEnvelope { type, source, capturedAt, hash, redacted, artifactRef, confidence }` cho QA/browser/review agents.
- **Uncertainty:** 4 ảnh/8 MiB là implementation choice, chưa có public benchmark chứng minh tối ưu cho mọi task.

### 5. Runtime permission layer đang dịch chuyển về **monotonic restriction**

- **One-sentence summary:** Codex `main` thêm environment-specific `exec_policy` chỉ được restrict, không được chứa `allow` rules, đồng thời cached approval gắn với policy fingerprint. [Codex #38942, 17/08/2026](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929)
- **Affected skill area:** Permission boundaries, human approval, secure agent runtime, CI/CD agents.
- **Why it matters:** Lower-level environment không nên tự mở quyền vượt global/workspace intent; approval cũ cũng không nên survive khi policy đổi.
- **Practical implication:** Authority composition nên là intersection: `Global ∩ Workspace ∩ Environment ∩ Task ∩ HumanApproval`.
- **Priority:** **Critical**.
- **Confirmed facts:** Environment policy reject `allow`; restrictive overlay merge vào command policy; fingerprint tham gia approval cache key. [Source](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929)
- **Analysis:** Đây là pattern phù hợp cho QA agents, code-review agents, migration agents và production assistants vì quyền chỉ giảm dần theo scope.
- **Recommendation:** Regression-test `permission downgrade`, `approval invalidation`, `environment change`, `same command under new policy`.
- **Uncertainty:** Source-level feature; stable shipping chưa được xác nhận.

### 6. Secret scrubbing phải là **runtime invariant** sau environment merge

- **One-sentence summary:** Codex fix để `CODEX_EXEC_SERVER_NOISE_AUTH_TOKEN` không inherited xuống shell commands/hooks, kể cả khi environment override cố thêm lại biến bằng casing khác. [Codex #38941, 17/08/2026](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)
- **Affected skill area:** Hooks, subprocess isolation, secret management, CI/CD security.
- **Why it matters:** Prompt không thể bảo vệ secret khỏi process child nếu runtime vẫn truyền environment.
- **Practical implication:** .NET runners nên sanitize `ProcessStartInfo.Environment` sau mọi merge/override và ngay trước process spawn.
- **Priority:** **Critical**.
- **Confirmed facts:** Commit có case-insensitive removal và regression tests cho shell commands/hooks. [Source](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)
- **Analysis:** Child process, hook và tool plugin phải được coi là untrusted boundary.
- **Recommendation:** Dùng allowlist cho high-risk runners; log tên biến bị scrub nhưng không log values.
- **Uncertainty:** Fix một secret không chứng minh mọi secret class đều đã được cover.

### 7. `Project ≠ Thread ≠ Run` tiếp tục là state model đáng học từ Codex app-server

- **One-sentence summary:** Experimental Codex Project APIs hỗ trợ project lifecycle, roots, metadata, thread assignment, fork inheritance và notifications. [Codex #38940, 17/08/2026](https://github.com/openai/codex/commit/3b4569a920f6442a23ad724a922810ac5ed1dd2a)
- **Affected skill area:** Agent memory/state, retries, context handoff, multi-agent coordination.
- **Why it matters:** Conversation transcript không nên là durable state store duy nhất.
- **Practical implication:** Long-running QA/research/interview/code-review systems nên model `Project → Run/Thread → Step/ToolCall → Artifact/Evidence`.
- **Priority:** **High**.
- **Confirmed facts:** Project delete clears thread assignment nhưng không xóa thread; forked threads inherit project association; project change notifications tồn tại. [Source](https://github.com/openai/codex/commit/3b4569a920f6442a23ad724a922810ac5ed1dd2a)
- **Analysis:** Lifecycle separation giúp resume, fork, audit, retry và regression testing rõ hơn.
- **Recommendation:** Chuẩn hóa `ProjectContext`, `RunContext`, `Checkpoint`, `Evidence`, `Decision`, `Artifact`.
- **Uncertainty:** API experimental; naming/schema có thể đổi.

## 3. Prompt, Skills, Rules, and Context Engineering

### A. Tạo **Resolved Capability Profile** thay vì hard-code behavior theo model name

- **Problem:** Agent code thường chứa `if model == ...` hoặc một bảng hard-code context/tool/threshold rải rác.
- **Proposed improvement:** Resolve một object duy nhất trước run:

```text
ResolvedCapabilityProfile
├─ modelIdentity
├─ contextLimits
├─ toolCapabilities
├─ multimodalCapabilities
├─ reviewDefaults
├─ permissionHints
├─ tokenBudgets
├─ providerRoute
├─ authMode
└─ sourceVersions
```

- **Why it may work:** Codex vừa đưa Guardian defaults vào model catalog và vẫn cho local override có precedence. [Codex #38990](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)
- **Suitable use cases:** Multi-model coding agents, QA/research agents, model routers, OpenAI/Anthropic/OpenCode gateways.
- **Limitations:** Capability profile phải được versioned và refreshed; stale profile có thể gây lỗi khó thấy.
- **Risks:** Nếu server-controlled defaults thay đổi mà không log resolved values, regression có thể bị nhầm thành model-quality change.

### B. Config provenance nên là một phần của observability

- **Problem:** Khi nhiều config layer chồng nhau, chỉ log final value không đủ để debug.
- **Proposed improvement:** Với mỗi setting quan trọng, log:

```text
review.threshold = 0.72
source = local-config
fallback = model-catalog:0.65
model = gpt-X
policyRevision = 2026-08-17.3
```

- **Why it may work:** Codex #38990 explicitly bảo toàn local overrides trong khi merge model defaults, tức provenance/precedence là behavior quan trọng.
- **Suitable use cases:** Safety reviewer, code-review agent, deployment agent, model comparison.
- **Limitations:** Telemetry nhiều hơn; cần tránh log prompt/secret nhạy cảm.
- **Risks:** Nếu log full classifier prompt hoặc secret-bearing config, observability tự tạo data leak.

### C. Skill catalog metadata nên tối ưu cho **routing**, full procedure chỉ load sau selection

- **Problem:** Skill description dài làm catalog nhanh chạm token budget.
- **Proposed improvement:** Discovery metadata chỉ giữ `name`, `trigger`, `outcome`, `exclusions`, `required tools`; procedure/examples/commands load sau.
- **Why it may work:** Codex skill catalog hiện có explicit budget và cap. [Codex #38978](https://github.com/openai/codex/commit/632e35ce8d5dec43b75dbf99f9e6fa52bed47c3d)
- **Suitable use cases:** Cursor rules/skills, Claude Code reusable instructions, Codex skills, role-based agent packs.
- **Limitations:** Metadata quá ngắn có thể giảm routing recall.
- **Risks:** Ambiguous skill names tạo wrong-skill invocation.

### D. Multimodal context phải có budget riêng

- **Problem:** Text tokens và image payload là hai loại resource khác nhau nhưng thường bị quản như một history chung.
- **Proposed improvement:** Track riêng `image_count`, `image_bytes`, `visual_priority`, `redacted`, `dedupe_hash`, `capturedAt`.
- **Why it may work:** Guardian v2 dùng bounded image count và bytes, độc lập với text transcript token limits. [Codex #38987](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e)
- **Suitable use cases:** Playwright QA, browser automation, incident/debug agents, screenshot code review.
- **Limitations:** Chưa có generic optimal budget.
- **Risks:** Deduplication quá aggressive có thể bỏ ảnh chứa subtle visual change.

## 4. Agent, Workflow, and Loop Engineering

### A. Thêm bước **Resolve → Execute → Verify** trước Plan-Execute-Verify truyền thống

**Problem:** Agent có thể lập plan bằng assumptions sai về model/tool/context/policy capabilities.

**Technique:**

```text
Resolve Capabilities & Policies
→ Plan
→ Execute
→ Verify
→ Decide
→ Persist Evidence/Checkpoint
```

- **Expected benefit:** Giảm failure do capability mismatch, ví dụ workflow tưởng có image verifier nhưng current route không support, hoặc policy không cho command.
- **Failure risks:** Resolver stale hoặc over-trust model catalog.
- **Suitable use cases:** Multi-provider coding agents, CI agents, review agents, model routing.
- **Confirmed facts supporting pattern:** Codex #38990 cho thấy review defaults có thể đến từ model metadata, còn #38942 cho thấy command authority phụ thuộc environment policy. [Model defaults](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7) · [Exec policy](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929)
- **Recommendation:** Capability resolution nên fail closed khi critical field unknown.

### B. Reviewer phải được versioned như production code

- **Problem:** LLM-as-a-judge hoặc safety reviewer thay đổi threshold/prompt/reasoning mà evaluation không lưu version.
- **Technique:** Mỗi verdict lưu:

```text
reviewerModel
reviewerConfigHash
classifierInstructionHash
threshold
reasoningEffort
transcriptPolicyHash
policyRevision
inputEvidenceHash
```

- **Expected benefit:** Có thể reproduce false positive/false negative và phân biệt model regression với config regression.
- **Failure risks:** Hash không đủ nếu upstream provider behavior thay đổi không versioned.
- **Suitable use cases:** QA verifier, PR review agent, interview-answer evaluator, research fact-check agent.
- **Analysis:** Codex #38990 làm review behavior model-aware; vì vậy reviewer config đã trở thành independent evaluation variable.

### C. `Evidence symmetry` cho executor và verifier

- **Problem:** Executor sử dụng screenshot, browser DOM hoặc tool output nhưng verifier chỉ nhận summary text.
- **Technique:** Xác định evidence contract chung; verifier nhận cùng class evidence nhưng bounded/redacted.
- **Expected benefit:** Giảm verdict dựa trên incomplete reconstruction.
- **Failure risks:** Privacy/cost tăng; evidence có thể chứa secrets/PII.
- **Suitable use cases:** Playwright QA, UI regression, incident triage.
- **Confirmed facts supporting pattern:** Guardian v2 image transcript forwarding. [Codex #38987](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e)

### D. `NO_MATERIAL_DELTA` là stop condition hợp lệ

- **Problem:** Research/monitoring agents thường tiếp tục search để “có đủ nội dung”.
- **Technique:** Stop khi primary sources không thay đổi sau watermark và không có release/advisory/benchmark mới.
- **Expected benefit:** Giảm repeated search, tokens và duplicated reports.
- **Failure risks:** Hosted/private rollout có thể không xuất hiện ở public repo.
- **Suitable use cases:** Daily briefings, release monitors, security watches.
- **Recommendation:** Watermark nên theo `source + commit/release id + checkedAt`, không chỉ timestamp.

### Security pattern nên ưu tiên: secret sanitizer cho child processes

- **Confirmed facts:** Codex #38941 scrub credential sau environment policy overrides và case-insensitively. [Source](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)

## 7. Opportunities and Trends to Watch

### Trend 1. **Model metadata đang trở thành runtime configuration plane**

- **What is changing:** Model catalog không chỉ mô tả context/tool support mà bắt đầu mang behavior defaults cho reviewer/safety configuration.
- **Why it matters:** Agent runtime có thể trở nên model-aware mà không hard-code logic cho từng model family.
- **Opportunity:** Xây capability resolver/vendor-neutral registry cho .NET agent systems.
- **Risk:** Remote defaults thay đổi làm behavior drift nếu không version/log.
- **Status:** **Early signal**.
- **Evidence:** Codex #38990. [Source](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)

### Trend 2. **Context budget đang phân mảnh theo surface**

- **What is changing:** Skill catalog có token budget riêng; visual evidence có count/byte budget; transcript/action/compaction cũng có limits riêng.
- **Why it matters:** “Context window lớn” không thay thế context engineering; cần allocation policy.
- **Opportunity:** Build `ContextBudgetManager` có metrics theo surface.
- **Risk:** Over-budgeting/cutting làm mất critical evidence.
- **Status:** **Growing**.
- **Evidence:** [Skill budget](https://github.com/openai/codex/commit/632e35ce8d5dec43b75dbf99f9e6fa52bed47c3d) · [Guardian images](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e) · [Guardian model defaults](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)

### Trend 3. **Permission systems chuyển từ prompt rules sang runtime enforcement**

- **What is changing:** Environment policy có monotonic restriction; approval cache gắn policy fingerprint; secret scrub được enforce ở process boundary.
- **Why it matters:** Model compliance không đủ cho production-grade safety.
- **Opportunity:** .NET agent execution host với permission engine + approval state + process sandbox abstraction.
- **Risk:** Policy complexity có thể tạo false block hoặc accidental over-permission.
- **Status:** **Growing**.
- **Evidence:** [Exec policy](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929) · [Secret scrub](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)

### Trend 4. **Verifier đang trở thành multimodal và stateful hơn**

- **What is changing:** Guardian v2 có transcript selection, model-aware defaults và optional visual evidence.
- **Why it matters:** Reviewer không còn chỉ là “send final text to another model”.
- **Opportunity:** QA verifier có evidence contract, threshold tuning, deterministic checks + LLM judge.
- **Risk:** Cost, privacy và complexity tăng; LLM judge vẫn cần deterministic validation.
- **Status:** **Experimental**.
- **Evidence:** [Guardian image support](https://github.com/openai/codex/commit/37cf6c84c086229ed78d69e726b965c0252e9b3e) · [Guardian model defaults](https://github.com/openai/codex/commit/8bf50439f2ebbcd98785c858e22174f919451cf7)

### Trend 5. **Provider abstraction không đồng nghĩa protocol flattening**

- **What is changing:** OpenCode giữ native OpenAI Responses path và Anthropic Messages path qua gateway thay vì ép mọi provider vào một compat protocol.
- **Why it matters:** Reasoning/tool semantics có thể mất khi normalization quá mạnh.
- **Opportunity:** Kiến trúc `Normalized Domain Interface + Provider-Native Adapter` cho agent platform.
- **Risk:** Adapter matrix và regression burden tăng.
- **Status:** **Growing**.
- **Evidence:** [OpenCode native passthrough, 17/08/2026](https://github.com/anomalyco/opencode/commit/cba6b5f2f74080239cdc7405efcb83219c980136)
