# AI Skills & Agent Engineering Briefing — 2026-08-18 18:00 (UTC+7)

## 1. Executive Summary

### 1. Agent engineering đang dịch chuyển sang reliability engineering
**Confirmed facts:** AI agents cần tool control, validation, permissions, observability và human approval để vận hành an toàn.

**Analysis:** Model capability chỉ là một phần; workflow, guardrails và verification quyết định độ tin cậy production.

**Recommendation:** Thiết kế agent với least privilege, audit log và approval boundary.

**Priority:** Critical

### 2. Context engineering trở thành lớp kiến thức của repository
**Confirmed facts:** Coding agents hỗ trợ instructions, rules và project context.

**Analysis:** Repository có cấu trúc knowledge giúp agent hiểu architecture, convention và constraint tốt hơn.

**Recommendation:** Duy trì AI knowledge layer gồm ADR, coding rules, testing strategy và security rules.

**Priority:** High

### 3. AI coding cần verification loop bắt buộc
**Confirmed facts:** Generated code cần compiler, automated tests và review.

**Analysis:** Tốc độ tạo code tăng nhưng regression risk cũng tăng nếu thiếu kiểm tra.

**Recommendation:** Chuẩn hóa Plan → Implement → Test → Review → Verify.

**Priority:** High

### 4. MCP và integrations cần được quản trị như production APIs
**Confirmed facts:** Agent có thể truy cập tools và external resources thông qua integration protocols.

**Analysis:** Tool access mở rộng năng lực nhưng tạo thêm security surface.

**Recommendation:** Áp dụng permission scope, logging và approval flow.

**Priority:** High

## 4. Agent, Workflow, and Loop Engineering

### Reliable Agent Loop

**Problem:** Agent có thể tạo kết quả hợp lý nhưng sai business requirement.

**Technique:**

Plan → Execute → Test → Review → Fix → Retest

**Controls:** Retry budget, checkpoints, failure classification, progress tracking, stop conditions, human approval.

**Expected benefit:** Giảm low-value loops và tăng khả năng debug.

**Failure risks:** Agent vẫn phụ thuộc chất lượng requirement.

**Suitable use cases:** Bug fixing, CI diagnosis, migration, refactoring, test generation.
