# AI Skills & Agent Engineering Briefing — 2026-08-18 18:00 (UTC+7)

## 1. Executive Summary

### 1. Agent governance trở thành yêu cầu production
- Confirmed facts: AI agents ngày càng cần policy, permission boundary, audit trail và human approval.
- Analysis: Giá trị của agent không chỉ nằm ở khả năng sinh code mà ở khả năng hoạt động an toàn trong workflow thật.
- Recommendation: Thiết kế agent với least privilege, approval gates và logging.
- Priority: Critical.

### 2. Context engineering vượt lên trên prompt engineering
- Confirmed facts: Coding agents hỗ trợ repository instructions, reusable rules và project context.
- Analysis: Knowledge layer của repository quyết định chất lượng output lâu dài.
- Recommendation: Version control AI rules cùng source code.
- Priority: High.

### 3. Verification loop là phần bắt buộc của AI-assisted development
- Confirmed facts: Generated code cần build, test và review thay vì chỉ kiểm tra bằng mắt.
- Analysis: Agent nhanh nhưng không có verification dễ tạo technical debt.
- Recommendation: Chuẩn hóa Plan → Execute → Test → Review → Verify.
- Priority: High.

**Confirmed facts:** Các nền tảng như Claude Code, OpenAI Codex, Cursor, GitHub Copilot và IDE agents tiếp tục phát triển theo hướng task delegation.

## 4. Agent, Workflow, and Loop Engineering

### Reliable Agent Loop

**Technique:**

Plan → Implement → Test → Review → Fix → Retest

**Control points:**
- Retry limit.
- Checkpoint.
- Stop condition.
- Human approval.
- Evidence collection.

**Suitable use cases:**
- Bug fixing.
- Refactoring.
- CI failure analysis.
- Architecture migration.
