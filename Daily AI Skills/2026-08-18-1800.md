# AI Skills & Agent Engineering Briefing — 2026-08-18 18:00 (UTC+7)

## 1. Executive Summary

### 1. Agent reliability đang chuyển từ prompt sang engineering system
**Confirmed facts:** AI agents cần workflow control, tool permissions, validation và observability để hoạt động an toàn.

**Analysis:** Giá trị production đến từ hệ thống bao quanh model, không chỉ từ model capability.

**Recommendation:** Thiết kế agent với permission boundary, audit trail và human approval cho hành động quan trọng.

**Priority:** Critical

### 2. Context engineering trở thành kỹ năng cốt lõi
**Confirmed facts:** Các coding agent hỗ trợ repository instructions, reusable rules và project context.

**Analysis:** Context có cấu trúc giúp giảm ambiguity khi agent xử lý codebase lớn.

**Recommendation:** Xây dựng AI knowledge layer gồm architecture, conventions, ADR, testing và security rules.

**Priority:** High

### 3. Verification loop là bắt buộc khi dùng AI coding
**Confirmed facts:** Code sinh bởi AI cần được kiểm tra bằng compiler, tests và review.

**Analysis:** Tốc độ generate code tăng nhưng risk về regression cũng tăng nếu thiếu validation.

**Recommendation:** Chuẩn hóa vòng lặp Plan → Implement → Test → Review → Verify.

**Priority:** High

### 4. MCP và tool integration cần quản trị như production API
**Confirmed facts:** Agent có thể truy cập external tools và dữ liệu thông qua integration protocols.

**Analysis:** Mở rộng quyền truy cập làm tăng năng lực nhưng cũng tăng attack surface.

**Recommendation:** Áp dụng least privilege, logging và approval workflow.

**Priority:** High

# 3. Prompt, Skills, Rules, and Context Engineering

## Repository AI Operating System

**Problem:** Prompt lớn chứa toàn bộ kiến thức dự án khó bảo trì.

**Proposed improvement:** Chuyển kiến thức thành artifacts:

- `.ai/rules/`

**Why it may work:** Agent có thể lấy context phù hợp theo nhiệm vụ thay vì nhận toàn bộ thông tin không cần thiết.

**Suitable use cases:**
- ASP.NET Core projects
- EF Core database design
- REST API review
- Architecture decisions
- QA automation

**Limitations:** Rules có thể lỗi thời hoặc xung đột.

**Risks:** Context quá nhiều làm giảm focus của agent.

# 4. Agent, Workflow, and Loop Engineering

## Reliable Agent Loop

**Problem:** Agent có thể tự tin hoàn thành nhưng kết quả chưa đúng.

**Technique:**

Plan → Execute → Test → Review → Fix → Retest

**Controls:**

- Retry budget
- Checkpoints
- Failure classification
- Progress tracking
- Human approval
- Stop conditions

**Expected benefit:** Giảm vòng lặp vô ích và tăng khả năng debug.

**Failure risks:** Agent vẫn có thể hiểu sai business requirement.

**Suitable use cases:**

- Bug fixing
- CI failure diagnosis
- Migration
- Large refactoring
- Test generation
