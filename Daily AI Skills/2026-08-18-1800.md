# AI Skills & Agent Engineering Briefing — 2026-08-18 18:00 (UTC+7)

## 1. Executive Summary

## 1. Agent workflow engineering trở thành năng lực cốt lõi
**Confirmed facts:** AI coding agents đang chuyển từ chat-based assistance sang workflows có tool use, repository context và nhiều bước thực thi. OpenAI Codex documentation mô tả agent workflow với khả năng làm việc trên codebase. https://developers.openai.com/codex/

**Analysis:** Điểm khác biệt lớn không còn nằm ở prompt dài hơn mà ở khả năng thiết kế vòng lặp: plan → execute → verify → recover.

**Recommendation:** Chuẩn hóa workflow AI cho .NET: phân tích requirement → tạo plan → code → chạy test → review diff → human approval.

**Uncertainty:** Hiệu quả phụ thuộc vào độ phức tạp dự án và chất lượng validation.

**Priority: Critical**

## 2. Repository rules và reusable skills trở thành engineering assets
**Confirmed facts:** Các AI coding tools hỗ trợ repository instructions/rules để cung cấp context ổn định. Cursor Rules là một ví dụ về cơ chế này. https://docs.cursor.com/context/rules

**Analysis:** Kiến thức kiến trúc, convention và business rules nên được version control cùng source code thay vì giữ trong chat.

**Recommendation:** Tạo các skills: .NET Architecture Review, EF Core Review, API Design Review, QA Test Planning.

**Priority: High**

## 3. MCP đang trở thành lớp tích hợp quan trọng cho agent
**Confirmed facts:** Model Context Protocol cung cấp chuẩn để model kết nối tools và external resources. https://modelcontextprotocol.io/

**Analysis:** Khi agent truy cập GitHub, database, file system hoặc internal API, permission boundary trở thành vấn đề kiến trúc.

**Recommendation:** Áp dụng least privilege và approval step cho các action có khả năng thay đổi dữ liệu.

**Priority: High**

## 4. Agent evaluation quan trọng hơn demo capability
**Confirmed facts:** Việc đánh giá agent cần kết hợp benchmark, deterministic validation và regression testing.

**Analysis:** Một agent tạo code nhanh nhưng tạo lỗi khó phát hiện không có giá trị production.

**Recommendation:** Xây bộ test cases cho code review agent và QA agent.

**Priority: High**

# 3. Prompt, Skills, Rules, and Context Engineering

## Problem
Prompt lớn khó maintain, dễ mất context và khó tái sử dụng.

## Improvement
Tách context thành:

- Repository rules.
- Role skills.
- Task workflow.
- Validation checklist.
- Architecture decisions.

## Why it may work
Agent nhận context đúng thời điểm thay vì phải đọc một prompt khổng lồ.

## Suitable use cases

- ASP.NET Core architecture review.
- EF Core migration.
- REST API design.
- Code review.
- Test planning.

## Risks

- Rules outdated.
- Skill routing sai.
- Context quá nhiều gây nhiễu.

# 4. Agent, Workflow, and Loop Engineering

## Problem
Agent dễ rơi vào vòng lặp sửa lỗi nhưng không tiến triển.

## Technique
Áp dụng:

Plan → Implement → Test → Review → Verify → Commit

Controls:

- Retry budget.
- Checkpoints.
- Stop conditions.
- Failure classification.
- Human approval.

## Expected benefit
Giảm low-value loops và tăng khả năng kiểm soát.

## Failure risks
Agent có thể đánh giá sai trạng thái hoàn thành.

## Suitable use cases

- Bug fixing.
- CI failure diagnosis.
- Refactoring.
- Architecture migration.
