# AI Skills & Agent Engineering Briefing — 2026-08-18 18:00 (UTC+7)

## 1. Executive Summary

### 1. Agent governance trở thành yêu cầu production
**Confirmed facts:** Production AI agents cần permission boundaries, approval flow, audit và kiểm soát tool access.

**Analysis:** Khả năng kiểm soát hành động quan trọng không kém khả năng sinh nội dung.

**Recommendation:** Thiết kế agent theo least privilege, human-in-the-loop và observability.

**Priority:** Critical

### 2. Context engineering thay thế prompt đơn lẻ
**Confirmed facts:** Coding agents hỗ trợ repository rules, instructions và reusable context.

**Analysis:** Context được tổ chức tốt giúp agent hiểu architecture, convention và constraint.

**Recommendation:** Lưu AI rules, ADR, coding standards trong repository.

**Priority:** High

### 3. Verification loop là phần bắt buộc của AI development
**Confirmed facts:** AI-generated code cần build, test, review và validation tự động.

**Analysis:** Tăng tốc coding nhưng không có verification sẽ làm tăng technical debt.

**Recommendation:** Chuẩn hóa Plan → Execute → Test → Review → Verify.

**Priority:** High

### 4. MCP mở rộng khả năng agent nhưng cần quản trị security
**Confirmed facts:** MCP cho phép agent truy cập tools và external resources.

**Analysis:** MCP nên được quản lý như API gateway cho agent.

**Recommendation:** Scope permission, logging và approval cho từng tool.

**Priority:** High

**Practical impact:** Hỗ trợ refactoring, debugging, test generation và review.

## 3. Prompt, Skills, Rules, and Context Engineering

### Repository AI Knowledge Layer
**Problem:** Prompt chứa toàn bộ kiến thức dự án khó maintain.

**Improvement:** Tách thành architecture rules, coding conventions, testing strategy, security constraints, deployment rules và domain knowledge.

**Why it may work:** Agent nhận đúng context theo nhiệm vụ thay vì context dư thừa.

**Risks:** Rules lỗi thời, conflict hoặc quá nhiều constraint.

## 4. Agent, Workflow, and Loop Engineering

### Reliable Agent Loop

**Technique:**
Plan → Execute → Test → Review → Fix → Retest

**Controls:** Retry budget, checkpoints, failure classification, progress tracking, human approval.

**Benefit:** Giảm low-value loops và tăng reliability.

**Risks:** Agent vẫn có thể hiểu sai business context.
