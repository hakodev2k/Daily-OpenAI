### 1. MCP chuyển sang giai đoạn production-oriented
- Confirmed facts: MCP specification 2026-07-28 giới thiệu stateless core, caching metadata, authorization hardening, Tasks extension và cập nhật SDK. (Model Context Protocol Blog, 2026-07-28)
- Analysis: Agent integration đang chuyển từ thử nghiệm local tool sang hạ tầng có khả năng scale.

- Priority: Critical.

- Analysis: Chất lượng production phụ thuộc verification loop hơn là prompt dài.
- Recommendation: Chuẩn hóa Plan → Execute → Test → Review → Verify.
- Priority: Critical.

### 3. Repository knowledge trở thành context layer quan trọng
- Confirmed facts: Nhiều AI coding tools hỗ trợ rules, instructions và reusable context.
- Analysis: Architecture decisions nên được lưu cùng codebase.

## 2. Tool and Platform Updates

### Model Context Protocol (MCP)

- Confirmed facts: MCP 2026-07-28 thay đổi core protocol theo hướng stateless, hỗ trợ scale qua HTTP infrastructure thông thường, bổ sung Tasks và cải thiện authorization. (MCP Specification update, 2026-07-28)
- Practical impact:
  - MCP server có thể triển khai phía sau load balancer.
  - Tool catalog có thể cache.
  - Long-running agent tasks dễ quản lý hơn.
- Affected workflow:
  - Database agent.
  - GitHub agent.
  - Documentation agent.
  - CI/CD agent.
- Recommendation: Test.

### Coding Agents

- Confirmed facts: AI coding assistants tiếp tục mở rộng khả năng code generation, review và repository reasoning.
- Analysis: Giá trị lớn nhất nằm ở việc kết hợp agent với deterministic validation.
- Recommendation: Không cho agent merge trực tiếp nếu chưa có test và approval.

## 4. Agent, Workflow, and Loop Engineering

### Problem
Agent có thể tạo vòng lặp sửa lỗi không hiệu quả.

### Technique
Áp dụng control loop:

1. Plan.
2. Execute.
3. Observe result.
4. Validate.
5. Decide continue/stop.

### Controls
- Retry budget.
- Checkpoints.
- Failure classification.
- Human approval.
- Rollback strategy.

### Suitable use cases
- Bug fixing.
- CI failure diagnosis.
- Large refactoring.
- Architecture migration.
