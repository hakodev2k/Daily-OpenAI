# 3. Prompt, Skills, Rules, and Context Engineering

## Problem
Một prompt lớn chứa tất cả kiến thức dự án khó maintain và khó dùng lại.

## Improvement
Tách thành:

- Repository rules.
- Role skills.
- Task-specific instructions.
- Validation checklist.
- Architecture decisions.

## Why it may work
Agent nhận đúng context tại đúng thời điểm, giảm context noise.

## Suitable use cases

- ASP.NET Core architecture review.
- EF Core migration.
- REST API design.
- Security review.
- Test planning.

## Limitations and risks

- Rules có thể lỗi thời.
- Quá nhiều rules gây conflict.
- Cần ownership rõ ràng.

# 4. Agent, Workflow, and Loop Engineering

## Problem
Agent dễ lặp lại nhiều lần khi không có tiêu chí dừng.

## Technique
Thiết kế loop:

Plan → Execute → Test → Review → Verify → Human approval

Control mechanisms:

- Retry budget.
- Checkpoints.
- Failure classification.
- Stop conditions.
- Progress tracking.

## Expected benefit
Giảm vòng lặp vô ích và tăng khả năng kiểm soát.

## Failure risks
Agent có thể đánh giá sai trạng thái hoàn thành.

## Suitable use cases

- Bug fixing.
- CI failure diagnosis.
- Refactoring.
- Architecture migration.
