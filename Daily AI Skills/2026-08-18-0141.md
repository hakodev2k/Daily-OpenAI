# AI Skills & Agent Engineering Briefing — 2026-08-18 01:41 (UTC+7)

## 1. Executive Summary

### 1. Agent engineering chuyển trọng tâm sang reliability
**Confirmed facts:** AI agents ngày càng cần permission boundaries, tool control, approval flow và validation thay vì chỉ sinh output.

**Analysis:** Production agent cần được thiết kế như một hệ thống phần mềm có state, policy và observability.

**Recommendation:** Với hệ thống .NET, áp dụng least privilege, audit log và human-in-the-loop cho tác vụ có quyền ghi.

**Priority:** Critical.

### 2. Repository context trở thành tài sản kỹ thuật
**Confirmed facts:** Coding agents hỗ trợ repository instructions, rules và reusable context.

**Analysis:** Chất lượng AI-assisted development phụ thuộc mạnh vào kiến thức dự án được cấu trúc.

**Recommendation:** Tạo AI knowledge layer gồm architecture rules, ADR, coding convention, testing strategy.

**Priority:** High.

### 3. Verification loop là thành phần bắt buộc
**Confirmed facts:** AI-generated code cần build, test và review tự động.

**Analysis:** Tăng tốc viết code nhưng không có verification sẽ làm tăng regression risk.

**Recommendation:** Chuẩn hóa Plan → Execute → Test → Review → Verify.

**Priority:** High.

### 4. MCP mở rộng năng lực agent nhưng cần governance
**Confirmed facts:** MCP cho phép agent truy cập tools và external resources.

**Analysis:** MCP nên được quản lý như API gateway với scope và permission rõ ràng.

**Recommendation:** Không expose tool rộng; dùng scoped access và logging.

**Priority:** High.

**Problem:** Prompt lớn chứa toàn bộ kiến thức dự án khó bảo trì.

## 4. Agent, Workflow, and Loop Engineering

### Reliable Agent Loop

**Problem:** Agent có thể lặp lại hoặc hoàn thành giả.

**Technique:**

Plan → Execute → Test → Review → Fix → Retest

**Control mechanisms:**

- Retry budget
- Checkpoints
- Failure classification
- Progress tracking
- Human approval

**Expected benefit:** Giảm vòng lặp vô ích và tăng khả năng dự đoán.

**Suitable use cases:** Bug fixing, CI diagnosis, migration, refactoring.
