## 3. Prompt, Skills, Rules, and Context Engineering

### Vấn đề
Prompt dài nhưng không có cấu trúc thường gây context drift.

### Improvement
Chuyển từ prompt-centric sang artifact-centric:

- `AGENTS.md` / repository rules
- Skill packages
- Architecture decision records
- Test strategy documents
- Coding conventions

### Why it may work
Agent có thể load đúng context theo task thay vì nhận toàn bộ thông tin.

### Use cases
- .NET Clean Architecture review
- EF Core migration review
- API design
- QA scenario generation

### Risks
- Rules quá nhiều làm agent bị conflict.
- Skill không được cập nhật dễ tạo output lỗi thời.

## 4. Agent, Workflow, and Loop Engineering

### Problem
Agent chạy lâu dễ rơi vào vòng lặp sửa lỗi nhưng không tiến triển.

### Technique
Áp dụng loop:

```
Plan
 -> Execute
 -> Validate
 -> Review evidence
 -> Decide continue/stop
```

### Expected benefit
- Giảm hallucinated fixes.
- Tăng khả năng debug production issue.
- Dễ audit.

### Failure risks
- Validation không đủ deterministic.
- Agent tự đánh giá sai kết quả.

### Suitable use cases
- Coding agent
- QA automation agent
- Research agent

## 5. Hooks and Integrations

| Integration | Benefit | Risk | Difficulty |
|-|-|-|-|
| MCP + Database | Agent truy vấn schema/data context | Data exposure | Moderate |
| GitHub Actions + AI review | Automatic PR analysis | False positive | Moderate |
| Teams/Slack agent | Incident assistant | Permission leakage | Advanced |
| Browser automation | Research/testing workflow | Session security | Experimental |

Recommendation: luôn dùng least-privilege token và approval gate cho action có side effect.
