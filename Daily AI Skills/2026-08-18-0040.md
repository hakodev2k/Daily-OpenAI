# AI Skills & Agent Engineering Briefing — 2026-08-18 00:40 (UTC+7)

## 1. Executive Summary

## 1. Agent workflow engineering tiếp tục là ưu tiên lớn
**Confirmed facts:** AI coding agents đang tập trung vào repository context, tool execution và nhiều bước xử lý thay vì chỉ trả lời chat. OpenAI Codex mô tả workflow làm việc với codebase và nhiệm vụ kỹ thuật. https://developers.openai.com/codex/

**Analysis:** Giá trị thực tế đến từ loop có kiểm soát: plan → execute → verify → recover.

**Recommendation:** Chuẩn hóa workflow cho .NET: requirement analysis → architecture plan → implementation → automated test → review → approval.

**Uncertainty:** Hiệu quả phụ thuộc vào validation và độ phức tạp của hệ thống.

**Priority: Critical**

## 2. Repository instructions trở thành tài sản kỹ thuật
**Confirmed facts:** Các AI coding tools hỗ trợ repository rules/instructions để cung cấp context ổn định. Cursor Rules là một ví dụ. https://docs.cursor.com/context/rules

**Analysis:** Coding convention, architecture decision và business rule nên được version control.

**Recommendation:** Tạo bộ rules cho Clean Architecture, EF Core, API design, testing và code review.

**Priority: High**

## 3. MCP mở rộng khả năng của agent nhưng cần governance
**Confirmed facts:** Model Context Protocol cung cấp chuẩn kết nối model với tools và resources. https://modelcontextprotocol.io/

**Analysis:** Khi agent truy cập GitHub, database hoặc internal API, permission boundary trở thành vấn đề kiến trúc.

**Recommendation:** Áp dụng least privilege, approval gate và audit log.

**Priority: High**

## 4. Agent evaluation quan trọng hơn demo
**Confirmed facts:** Agent production cần benchmark, deterministic validation và regression testing.

**Analysis:** Agent nhanh nhưng tạo lỗi khó phát hiện không tạo ra giá trị.

**Recommendation:** Xây benchmark cho QA agent, review agent và architecture agent.

**Priority: High**

# 4. Agent, Workflow, and Loop Engineering

**Problem:** Agent có thể lặp sửa lỗi nhưng không tiến triển.

**Technique:**
- Plan trước khi code.
- Checkpoint sau mỗi bước.
- Retry budget.
- Stop condition.
- Human approval cho action nguy hiểm.

**Expected benefit:** Giảm vòng lặp vô ích và tăng khả năng kiểm soát.

**Failure risks:** Agent đánh giá sai trạng thái hoàn thành.

**Suitable use cases:** Bug fixing, CI failure, refactoring, migration.
