# AI Skills & Agent Engineering Briefing — 2026-08-17 22:30 (UTC+7)

## 1. Executive Summary

### 1. Agent engineering chuyển sang hướng reliability-first
- **Confirmed:** Các hệ thống agent hiện đại tập trung nhiều hơn vào telemetry, verification, policy và evaluation thay vì chỉ tối ưu prompt.
- **Analysis:** Với developer xây dựng AI workflow, điểm khác biệt nằm ở khả năng kiểm soát vòng đời agent.
- **Recommendation:** Thiết kế agent như một production service có state, logs, metrics và failure handling.
- **Priority:** Critical.

### 2. Skill routing quan trọng hơn việc nạp toàn bộ context
- **Confirmed:** Pattern sử dụng metadata, routing và lazy loading instructions đang được áp dụng trong agent systems.
- **Analysis:** Inject toàn bộ rules vào context làm tăng cost và giảm khả năng tập trung.
- **Recommendation:** Tách skill discovery, skill selection và skill execution.
- **Priority:** High.

### 3. Verification loop trở thành thành phần bắt buộc
- **Confirmed:** Agent coding workflows ngày càng kết hợp test, review và validation sau khi generate code.
- **Analysis:** Code generation không đủ để đảm bảo production quality.
- **Recommendation:** Áp dụng Plan → Execute → Verify → Commit State.
- **Priority:** High.

## 2. Tool and Platform Updates

### AI coding agents
- **Confirmed:** Các coding agent đang mở rộng từ autocomplete sang multi-step execution, tool calling và repository understanding.
- **Impact:** Developer cần quản lý context, permissions và validation thay vì chỉ viết prompt.
- **Recommendation:** Test trên repository nhỏ trước khi đưa vào production workflow.

**Uncertainty:** Feature availability thay đổi nhanh theo từng provider và release channel.

## 3. Prompt, Skills, Rules, and Context Engineering

### Vấn đề
Static rules lớn làm context window bị tiêu hao.

### Cải tiến
Thiết kế:
- skill metadata
- routing criteria
- reusable instructions
- scoped repository rules

### Use cases
- Cursor rules
- Codex skills
- Claude Code workflows
- QA agents
- Architecture review agents

### Risk
Routing sai có thể khiến agent chọn sai capability.

## 4. Agent, Workflow, and Loop Engineering

### Kỹ thuật khuyến nghị

```
Plan
 ↓
Execute
 ↓
Verify
 ↓
Store State
 ↓
Continue / Stop
```

### Retry strategy
Cần có:
- retry budget
- error classification
- idempotent actions
- stop conditions

### Benefit
Giảm infinite loop, giảm chi phí token và tránh automation chạy sai hướng.
