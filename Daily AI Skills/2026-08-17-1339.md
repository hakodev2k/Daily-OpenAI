## 3. Prompt, Skills, Rules, and Context Engineering

### A. Đưa “capability/version assumptions” ra khỏi prompt và vào machine-readable state

- **Problem:** Prompt thường chứa các câu như “tool hỗ trợ X”, “model có context Y”, “config path là Z”. Những assumption này nhanh stale khi tool update.
- **Proposed improvement:** Tách runtime facts thành `capabilities.json` hoặc state object:

```json
{
  "tool": "codex",
  "version": "0.147.0",
  "observedAt": "2026-08-17T13:39:00+07:00",
  "capabilities": {
    "environmentExecPolicy": false,
    "projectApi": false
  }
}
```

- **Why it may work:** Prompt chỉ nên mô tả intent/policy; runtime capability nên được probe và versioned để tránh instruction drift.
- **Suitable use cases:** Codex/Claude/Cursor skills, QA agent, internal developer platform, multi-model harness.
- **Limitations:** Cần maintain probe logic.
- **Risks:** Probe sai hoặc stale cache vẫn gây wrong behavior.
- **Confirmed fact:** Codex stable release hiện vẫn `0.147.0` trong khi main đã chứa features mới, minh họa chính xác khoảng cách giữa source và runtime capability. [Codex stable](https://github.com/openai/codex/releases/tag/rust-v0.147.0)
- **Recommendation:** Mỗi reusable Skill nên khai báo `requiresCapabilities` thay vì chỉ ghi text “requires recent Codex”.
- **Uncertainty:** Không có universal schema cross-vendor cho capability declaration.

### B. Rules nên mô tả invariants; Skills nên mô tả procedure; permission policy không nên nằm trong natural-language prompt

- **Problem:** Nếu “không chạy destructive command” chỉ là một câu trong prompt, model vẫn là enforcement point.
- **Proposed improvement:**
  - **Rules:** architecture/coding invariants.
  - **Skills:** procedural steps.
  - **Runtime policy:** executable deny/allow constraints.
  - **Verifier:** deterministic post-condition checks.
- **Why it may work:** Codex environment policy change cho thấy runtime layer có thể phủ định action independent of model intent. [Commit #38942](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929)
- **Suitable use cases:** migration agents, deployment agents, DB tools, Git push/PR automation.
- **Limitations:** Policy engine làm system phức tạp hơn.
- **Risks:** Over-restrictive policy tạo friction và false blocking.
- **Recommendation:** Prompt nói “what/why”; runtime policy quyết định “may/may not”.

### C. Context budgeting cần dựa trên observed capability + safety margin

- **Problem:** Hard-coded limit dễ stale; input budget thường không bằng total context.
- **Proposed improvement:** `usableInput = advertisedInput × safetyFactor - reservedOutput - toolOverhead`.
- **Why it may work:** OpenCode vừa phải sửa GPT-5.6 metadata cho một access path cụ thể. [Commit #39082](https://github.com/anomalyco/opencode/commit/4d68d30b48a99379b2baaf597dbad576707ea36d)
- **Suitable use cases:** long research, repository-wide analysis, interview graph generation, knowledge synthesis.
- **Limitations:** Tool-call payload và hidden/system context vẫn có thể thay đổi.
- **Risks:** Compaction quá sớm làm mất evidence; quá muộn gây request failure.
- **Recommendation:** Log actual prompt token size trước request và compaction trigger reason.

## 4. Agent, Workflow, and Loop Engineering

### A. Thêm “Release Gate” trước khi agent dùng một capability mới

- **Problem:** Agent instruction có thể được update theo main branch trong khi runtime vẫn là stable cũ.
- **Technique:** Trước execution, gate theo `tool version → capability probe → fallback`.
- **Expected benefit:** Tránh workflow fail vì capability chưa ship.
- **Failure risks:** Version parsing hoặc custom builds có thể làm mapping sai.
- **Suitable use cases:** Codex managed config, project APIs, permission policies.
- **Recommendation:** Prefer feature probe hơn pure semver mapping khi có thể.

### B. Approval cache phải gắn với policy state

- **Problem:** User từng approve một command ở policy cũ; environment policy sau đó siết quyền nhưng cached approval vẫn được reuse sẽ tạo privilege bypass logic.
- **Technique:** Cache key = `action + environment + policyFingerprint + relevant resource scope`.
- **Expected benefit:** Policy update có hiệu lực ngay, không cần nhớ xóa mọi approval cache thủ công.
- **Confirmed fact:** Codex commit #38942 đưa environment policy fingerprint vào cached approval keys. [Source](https://github.com/openai/codex/commit/e38290846c11424567c9c8226f2be8a2886c5929)
- **Failure risks:** Frequent policy changes giảm cache hit và tăng prompt approvals.
- **Suitable use cases:** shell commands, Git operations, DB writes, cloud actions.

### C. Secret scrub nên là một deterministic pre-exec phase

- **Problem:** Hooks/child process có thể quan sát runtime secrets.
- **Technique:** `ResolveEnv → MergeOverrides → StripNonInheritable → Allowlist/Validate → Spawn`.
- **Expected benefit:** giảm accidental credential exposure.
- **Confirmed fact:** Codex hardening test rõ việc scrub sau overrides và case-insensitive removal. [Source](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)
- **Failure risks:** Một build tool thật sự cần credential có thể bị break.
- **Suitable use cases:** QA agents, CI runners, code execution sandboxes, hooks.
- **Recommendation:** Secrets cần thiết nên được delegated theo short-lived task token thay vì inherited control-plane token.

### D. Khi không có new signal, loop monitoring phải stop

- **Problem:** Research agent có thể tiếp tục search cùng nguồn dù không có delta mới.
- **Technique:** Stop condition: `no new release/commit/change since last checkpoint → stop research branch → emit no-change state`.
- **Expected benefit:** giảm tool calls, latency, duplicated output và hallucinated novelty.
- **Suitable use cases:** daily briefings, release monitors, job radars, market/news agents.
- **Recommendation:** Persist last-seen IDs/timestamps và diff trước khi deep-read.

## 5. Hooks and Integrations

### 1. Pre-exec policy hook cho .NET agent runner

- **What can be integrated:** command classifier + environment policy + approval service trước `Process.Start`.
- **Workflow benefit:** runtime enforcement độc lập model.
- **Security concerns:** policy precedence phải deterministic; deny rules không được bị lower layer override.
- **Difficulty:** **Moderate**.
- **Suggested contract:** `Evaluate(command, cwd, environment, task) -> Allow | Deny | NeedsApproval`.

### 2. Environment sanitizer cho child processes và hooks

- **What can be integrated:** một .NET component tạo environment dictionary sạch trước mỗi external process.
- **Workflow benefit:** giảm credential leak từ build/test/tool ecosystem.
- **Security concerns:** Windows env names case-insensitive; cần test variant casing.
- **Difficulty:** **Easy–Moderate**.
- **Evidence:** Codex hardening commit xử lý chính edge case này. [Source](https://github.com/openai/codex/commit/89e297729ebc1a8c243cef73c7ab64cd842ecd5a)

### 3. Provider gateway giữ native protocol

- **What can be integrated:** Cloudflare/Azure/custom gateway làm auth, routing, telemetry nhưng backend adapter vẫn dùng native OpenAI Responses hoặc Anthropic Messages khi cần.
- **Workflow benefit:** giữ tool/reasoning/provider semantics mà vẫn có centralized governance.
- **Security concerns:** gateway credential không được forward nhầm tới upstream third-party provider.
- **Difficulty:** **Advanced**.
- **Evidence:** OpenCode commit #42634 vừa chuyển theo pattern này. [Source](https://github.com/anomalyco/opencode/commit/cba6b5f2f74080239cdc7405efcb83219c980136)

### 4. Version/capability probe trong CI

- **What can be integrated:** GitHub Actions/Azure DevOps job đọc tool version và chạy smoke tests cho capability bắt buộc.
- **Workflow benefit:** phát hiện agent tool upgrade làm rule/skill/config incompatible trước khi developer gặp lỗi.
- **Security concerns:** CI không nên print secrets/config values nhạy cảm.
- **Difficulty:** **Easy**.

## 7. Opportunities and Trends to Watch

### Trend 1. Agent security đang dịch từ prompt policy sang runtime policy

- **What is changing:** Command restrictions, environment policies, sandbox permissions và approval state ngày càng được encode thành machine-enforced configuration.
- **Why it matters:** Prompt không phải security boundary.
- **Opportunity:** reusable policy engine cho local/CI/cloud agents; policy-as-code cho agent permissions.
- **Risk:** fragmented policy languages giữa vendors.
- **Status:** **Growing**.

### Trend 2. Agent runtime secrets sẽ cần workload identity thay vì inherited environment secrets

- **What is changing:** Tool/runtime designs đang harden việc không truyền credential control-plane xuống model-reachable subprocess.
- **Why it matters:** Agent chạy arbitrary tools nên được coi giống untrusted workload.
- **Opportunity:** short-lived scoped tokens, workload identity broker, per-tool credentials.
- **Risk:** implementation phức tạp hơn và cần refresh/retry logic.
- **Status:** **Growing**.

### Trend 3. Multi-provider gateways sẽ giữ native protocols ở những nơi feature parity quan trọng

- **What is changing:** Gateway vẫn centralized nhưng provider adapter có thể dùng native APIs thay vì một compatibility protocol duy nhất.
- **Why it matters:** reasoning, tool use, structured outputs và usage semantics phát triển không đồng đều giữa providers.
- **Opportunity:** .NET AI gateway abstraction với capability negotiation.
- **Risk:** code path nhiều hơn, test matrix lớn hơn.
- **Status:** **Growing**.

### Trend 4. Capability metadata trở thành configuration data có lifecycle riêng

- **What is changing:** context limits, feature support và permission behavior có thể khác theo version/access path.
- **Why it matters:** hard-coded constants trong agent code nhanh stale.
- **Opportunity:** model/tool capability registry + probes + regression tests.
- **Risk:** registry tự nó trở thành stale nếu không có source timestamp/probe.
- **Status:** **Established principle, growing implementation**.

### Trend 5. “No-change detection” là feature quan trọng của research agents

- **What is changing:** Scheduled agents chạy thường xuyên cần biết khi nào không nên tiếp tục deep research.
- **Why it matters:** Reliability không chỉ là tìm đúng thông tin; còn là không chế tạo novelty khi không có thay đổi.
- **Opportunity:** generic delta engine cho releases, jobs, markets, repos, documents.
- **Risk:** source metadata có thể lag hoặc hosted changes không xuất hiện trong public repo.
- **Status:** **Established pattern**, còn bị đánh giá thấp trong AI-agent workflows.
