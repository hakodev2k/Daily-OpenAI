## Đoạn code cần review

```csharp
[ApiController]
[Route("api/products")]
public sealed class ImageController : ControllerBase
{
    private readonly HttpClient _client;
    private readonly BlobContainerClient _container;
    private readonly IProductRepository _repo;
    public ImageController(HttpClient client, BlobContainerClient container,
        IProductRepository repo)
    {
        _client = client;
        _container = container;
        _repo = repo;
    }

    [HttpPost("{id:guid}/image")]
    public async Task<IActionResult> Import(Guid id, ImportImageRequest input)
    {
        var product = await _repo.FindAsync(id);
        if (product == null) return NotFound();

        using var response = await _client.GetAsync(input.Url);
        response.EnsureSuccessStatusCode();
        var bytes = await response.Content.ReadAsByteArrayAsync();
        var blob = _container.GetBlobClient($"{id}/{Guid.NewGuid()}.jpg");
        await blob.UploadAsync(new BinaryData(bytes), overwrite: true);
        product.ImageUrl = blob.Uri.ToString();
        await _repo.SaveAsync(product);
        return Ok(new { product.ImageUrl });
    }
}
public sealed record ImportImageRequest(string Url);
```

## Kết quả code review tham khảo

### [Critical] — SSRF

**Vấn đề:** URL bất kỳ được server gọi; redirect và DNS có thể dẫn đến loopback, private, link-local hoặc metadata endpoint.

**Tại sao xảy ra:** URL bất kỳ được server gọi; redirect và DNS có thể dẫn đến loopback, private, link-local hoặc metadata endpoint.

**Ảnh hưởng production:** Đọc tài nguyên nội bộ, lộ credential, quét mạng.

**Cách sửa:** Allowlist domain nhà cung cấp, HTTPS, disable redirect tự động hoặc validate từng hop; egress proxy/firewall chặn IP nguy hiểm tại lúc kết nối, không chỉ DNS pre-check.

### [High] — Broken object-level authorization

**Vấn đề:** Kiểm tra tồn tại sản phẩm nhưng không kiểm tra tenant/ownership và quyền edit.

**Tại sao xảy ra:** Kiểm tra tồn tại sản phẩm nhưng không kiểm tra tenant/ownership và quyền edit.

**Ảnh hưởng production:** Cross-tenant modification.

**Cách sửa:** Resource-based authorization và tenant-scoped query trước outbound I/O.

### [High] — Unbounded buffering

**Vấn đề:** GetAsync mặc định buffer response, ReadAsByteArrayAsync giữ toàn bộ file.

**Tại sao xảy ra:** GetAsync mặc định buffer response, ReadAsByteArrayAsync giữ toàn bộ file.

**Ảnh hưởng production:** OOM, GC pressure khi đồng thời nhiều import.

**Cách sửa:** ResponseHeadersRead, byte cap thực đọc, streaming và concurrency limit.

### [High] — Thiếu content validation

**Vấn đề:** Đuôi jpg được gán dù response có thể là HTML hoặc ảnh độc hại.

**Tại sao xảy ra:** Đuôi jpg được gán dù response có thể là HTML hoặc ảnh độc hại.

**Ảnh hưởng production:** Phân phối nội dung không an toàn, image decompression bomb.

**Cách sửa:** Kiểm tra magic bytes, decode với giới hạn pixel, re-encode JPEG, ContentType phù hợp.

### [High] — Thiếu cancellation/deadline

**Vấn đề:** Không truyền RequestAborted hoặc timeout riêng.

**Tại sao xảy ra:** Không truyền RequestAborted hoặc timeout riêng.

**Ảnh hưởng production:** Socket và worker bị giữ lâu.

**Cách sửa:** Linked CancellationTokenSource, deadline, outbound connection budget.

### [Medium] — Partial failure giữa Blob và DB

**Vấn đề:** Hai hệ lưu trữ không có atomic transaction.

**Tại sao xảy ra:** Hai hệ lưu trữ không có atomic transaction.

**Ảnh hưởng production:** Orphan blobs, retry tạo nhiều bản.

**Cách sửa:** Pending/Ready state, idempotency key, durable cleanup/reconciliation.

### [Medium] — Lost update khi concurrent import

**Vấn đề:** Hai request đọc cùng version rồi ghi URL không điều kiện.

**Tại sao xảy ra:** Hai request đọc cùng version rồi ghi URL không điều kiện.

**Ảnh hưởng production:** Ảnh mới bị ghi đè.

## Phiên bản đề xuất

```csharp
[Authorize(Policy = "ProductImageEditor")]
[ApiController]
[Route("api/products")]
public sealed class ImageController : ControllerBase
{
    private readonly IProductRepository _repo;
    private readonly IAuthorizationService _auth;
    private readonly IApprovedImageFetcher _fetcher;
    private readonly BlobContainerClient _blobs;
    public ImageController(IProductRepository repo,
        IAuthorizationService auth, IApprovedImageFetcher fetcher,
        BlobContainerClient blobs)
        => (_repo, _auth, _fetcher, _blobs) = (repo, auth, fetcher, blobs);

    [HttpPost("{id:guid}/image")]
    public async Task<IActionResult> Import(Guid id,
        ImportImageRequest input, CancellationToken ct)
    {
        var product = await _repo.FindForTenantAsync(id, User, ct);
        if (product is null) return NotFound();
        if (!(await _auth.AuthorizeAsync(User, product, "EditProductImage")).Succeeded)
            return Forbid();
        if (!Uri.TryCreate(input.Url, UriKind.Absolute, out var uri)
            || uri.Scheme != Uri.UriSchemeHttps)
            return BadRequest("Invalid URL");

        using var budget = CancellationTokenSource.CreateLinkedTokenSource(ct);
        budget.CancelAfter(TimeSpan.FromSeconds(25));
        await using var image = await _fetcher.FetchValidatedJpegAsync(
            uri, maxBytes: 8 * 1024 * 1024, budget.Token);
        var name = $"{id}/{Guid.NewGuid():N}.jpg";
        var blob = _blobs.GetBlobClient(name);
        await blob.UploadAsync(image, new BlobUploadOptions {
            HttpHeaders = new BlobHttpHeaders { ContentType = "image/jpeg" }
        }, budget.Token);
        try {
            await _repo.SetImageIfVersionMatchesAsync(
                id, product.Version, name, budget.Token);
        } catch {
            await _repo.RecordOrphanForReconciliationAsync(name, CancellationToken.None);
            throw;
        }
        return Ok(new { ImageId = name });
    }
}
```

## Giải thích thiết kế sau khi sửa

Đây là skeleton kiến trúc, không phải code chạy độc lập: IApprovedImageFetcher phải enforce domain allowlist, redirect policy, DNS/connect-time egress restrictions, streaming byte cap, deadline và decode/re-encode; repository cần concurrency token và durable orphan reconciliation. Không dùng CancellationToken.None vô hạn ở production: áp timeout riêng và outbox bền vững. Cần exception mapping sang 409/502/504 và private blob/CDN access policy.

## Trade-offs

Allowlist hạn chế nhà cung cấp; re-encode tăng CPU; queue/background job (202 Accepted) cải thiện isolation nhưng tăng eventual consistency và complexity; optimistic concurrency đòi hỏi UX xử lý conflict. Không mặc định cần microservices.

## Cách kiểm thử

1. SSRF: loopback/private/link-local, DNS rebinding và redirect tới metadata bị chặn tại egress.
2. Body chunked >8 MB, server chậm hoặc disconnect: memory/deadline giữ trong giới hạn.
3. Blob thành công, DB thất bại: orphan được reconcile, URL chưa public.
4. Hai import đồng thời cùng version: chỉ một update thành công.
5. Ảnh giả HTML, ảnh hỏng, decompression bomb bị từ chối.

## Quan sát trong production

Application Insights dependency spans theo host đã allowlist; duration p95, bytes downloaded, blocked URL count, invalid-image count, concurrency conflicts, orphan backlog; correlation ID. Không log full URL có token.

## Câu hỏi phỏng vấn mở rộng

1. CDN nhà cung cấp đổi IP liên tục: làm sao enforce egress policy đúng thời điểm connect?
2. Nếu phải retry import qua queue, idempotency key và trạng thái job được thiết kế thế nào?
3. Khi nào nên dùng browser direct upload thay vì server-side import?

## Phiên bản đề xuất

```vue
<script setup lang="ts">
import { ref, watch, onBeforeUnmount } from 'vue';
type Product = { id: string; name: string };
type Page = { items: Product[]; total: number };
const query = ref('');
const debounced = ref('');
const category = ref('all');
const page = ref(1);
const pageSize = 20;
const products = ref<Product[]>([]);
const total = ref(0);
const loading = ref(false);
const error = ref('');
let timer: ReturnType<typeof setTimeout> | undefined;
let generation = 0;
watch(query, value => {
  clearTimeout(timer);
  timer = setTimeout(() => { debounced.value = value; }, 300);
});
watch([debounced, category], () => { page.value = 1; });
watch([debounced, category, page], async (_, __, onCleanup) => {
  const controller = new AbortController();
  const current = ++generation;
  onCleanup(() => controller.abort());
  loading.value = true;
  error.value = '';
  const params = new URLSearchParams({
    query: debounced.value, category: category.value,
    page: String(page.value), pageSize: String(pageSize)
  });
  try {
    const response = await fetch('/api/products?' + params, {
      signal: controller.signal
    });
    if (!response.ok) throw new Error('HTTP ' + response.status);
    const data = await response.json() as Page;
    if (!Array.isArray(data.items) || !Number.isFinite(data.total))
      throw new Error('Invalid response');
    if (current !== generation) return;
    products.value = data.items;
    total.value = data.total;
  } catch (e) {
    if (current !== generation || controller.signal.aborted) return;
    error.value = e instanceof Error ? e.message : 'Request failed';
    products.value = [];
    total.value = 0;
  } finally {
    if (current === generation) loading.value = false;
  }
}, { immediate: true });
onBeforeUnmount(() => clearTimeout(timer));
</script>
<template>
  <input v-model="query" aria-label="Search products" />
  <select v-model="category" aria-label="Product category">
    <option value="all">All</option>
    <option value="books">Books</option>
    <option value="tools">Tools</option>
  </select>
  <p v-if="loading" role="status">Loading...</p>
  <p v-if="error" role="alert">{{ error }}</p>
  <p aria-live="polite">Found {{ total }}</p>
  <div v-for="p in products" :key="p.id">{{ p.name }}</div>
  <button :disabled="loading || page * pageSize >= total"
    @click="page++">Next</button>
</template>
```

## Giải thích thiết kế sau khi sửa

Generation guard bảo đảm chỉ request mới nhất cập nhật state; AbortController tiết kiệm network nhưng không thay thế guard. URLSearchParams encode chính xác. Vue interpolation escape text. Debounce áp dụng cho text search, category thay đổi tức thì. Skeleton cần xử lý filter đang gõ trong 300ms: invalidate request cũ ngay khi query thay đổi nếu UX yêu cầu kết quả luôn khớp input; nên gom filter/page vào request key duy nhất để tránh request trung gian khi reset page.

## Trade-offs

Debounce giảm tải nhưng tăng độ trễ 300ms; client cache cần invalidation; query library giảm boilerplate nhưng thêm dependency; abort phía client không bảo đảm backend dừng nếu không propagate CancellationToken. Không mặc định cần caching.

## Cách kiểm thử

1. Playwright đảo thứ tự hai response: chỉ request mới nhất hiển thị.
2. 429/500 và malformed JSON: báo lỗi đúng, không giữ stale data.
3. Đổi category từ page 8: về page 1 và Next disabled đúng.
4. Tên sản phẩm chứa HTML/script: chỉ render text.
5. Gõ 15 ký tự liên tiếp dưới network throttling: request count giảm, spinner đúng.
