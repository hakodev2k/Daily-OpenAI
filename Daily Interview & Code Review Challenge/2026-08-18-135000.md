# Câu 1 — EF Core Query Execution và vấn đề dữ liệu tăng đột biến

**Loại câu hỏi:** Internal mechanism trong production scenario
**Độ khó:** Senior

## Bối cảnh
Một API ASP.NET Core dùng EF Core để lấy danh sách đơn hàng. Sau khi dữ liệu tăng từ vài nghìn lên vài triệu bản ghi, latency tăng mạnh dù code không thay đổi.

## Câu hỏi chính
Giải thích EF Core thực thi query như thế nào, nguyên nhân có thể khiến hành vi thay đổi khi dữ liệu tăng, cách kiểm chứng và rủi ro production.

## Gợi ý tư duy
- Phân biệt LINQ expression và SQL execution.
- Kiểm tra generated SQL, execution plan.
- Đánh giá tracking, index và dữ liệu thực tế.

# Câu 2 — Thiết kế nền tảng Background Job cho hệ thống doanh nghiệp

**Loại câu hỏi:** System Design
**Độ khó:** Senior+

## Bối cảnh
Thiết kế hệ thống xử lý email, đồng bộ Microsoft Graph và các tác vụ nền với Hangfire/Azure Functions.

## Câu hỏi chính
Thiết kế giải pháp có retry, idempotency, monitoring và recovery.

## Gợi ý tư duy
- Xác định failure scenario trước khi chọn công nghệ.
- Thiết kế trạng thái job rõ ràng.
- Observability là phần bắt buộc.
