# Câu 1 — EF Core Query Execution trong hệ thống có dữ liệu lớn

**Loại câu hỏi:** Internal mechanism trong production scenario  
**Độ khó:** Senior

## Bối cảnh
Một API ASP.NET Core dùng EF Core trả danh sách dữ liệu. Sau vài tháng vận hành, dữ liệu tăng từ nghìn lên hàng triệu bản ghi và latency tăng dù business logic không đổi.

## Câu hỏi chính
Giải thích cơ chế EF Core chuyển LINQ thành SQL, query được thực thi khi nào, vì sao hiệu năng thay đổi, các hiểu nhầm thường gặp và cách kiểm chứng bằng công cụ production.

## Câu hỏi làm rõ nên cân nhắc
- Query thực tế, database engine và execution plan là gì?
- Có dùng tracking không?
- Có index phù hợp không?

## Gợi ý tư duy
- Phân biệt expression tree và SQL execution.
- Kiểm tra generated SQL và execution plan.
- Xem xét memory, tracking và database statistics.

# Câu 2 — Thiết kế nền tảng Background Job doanh nghiệp

**Loại câu hỏi:** System Design  
**Độ khó:** Senior+

## Bối cảnh
Một hệ thống cần xử lý email, đồng bộ Microsoft Graph, import dữ liệu và các tác vụ nền bằng Hangfire/Azure Functions. Một số job thất bại hoặc chạy trùng khi dependency bên ngoài không ổn định.

## Câu hỏi chính
Thiết kế kiến trúc xử lý background job có retry, idempotency, monitoring và recovery.

## Gợi ý tư duy
- Thiết kế failure scenario trước.
- Xác định trạng thái job.
- Observability phải là một phần của thiết kế.

# Câu 3 — AI Agent hỗ trợ Code Review

**Loại câu hỏi:** AI Engineering  
**Độ khó:** Senior+

## Bối cảnh
Team muốn xây dựng agent dùng OpenAI API để review pull request C#/.NET, phát hiện bug, security issue và đề xuất cải thiện.

## Câu hỏi chính
Thiết kế workflow AI agent với context, tools, permissions, validation và evaluation.

## Gợi ý tư duy
- Không giao toàn bộ quyết định cho LLM.
- Context cần chọn lọc.
- Output phải có bước kiểm chứng.

# Tổng kết hôm nay

## Kiến thức trọng tâm
- Hiểu runtime behavior trước khi tối ưu.
- Thiết kế dựa trên failure mode và observability.
- Kết hợp AI với validation deterministic.

## Mẫu tư duy cần nhớ
- Clarify before designing.
- Measure before optimizing.
- Design retries together with idempotency.
- Validate AI output deterministically.
