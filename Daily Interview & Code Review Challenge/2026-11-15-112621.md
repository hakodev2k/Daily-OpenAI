## Bối cảnh

Sau rollout caching, người dùng đôi khi thấy nội dung chưa xuất bản, cập nhật đã publish xuất hiện chậm, và một tenant thấy banner của tenant khác. ## Đoạn code cần review

```csharp
[ApiController]
[Route("api/content")]
public sealed class ContentController : ControllerBase
{
    private readonly IContentReader _reader;
    private readonly IMemoryCache _cache;
    private readonly ILogger<ContentController> _logger;

    public ContentController(
        IContentReader reader,
        IMemoryCache cache,
        ILogger<ContentController> logger)
    {
        _reader = reader;
        _cache = cache;
        _logger = logger;
    }

    [HttpGet("{slug}")]
    public async Task<IActionResult> Get(
        string slug,
        [FromQuery] string? language,
        [FromQuery] bool preview = false,
        CancellationToken ct = default)
    {
        var tenant = Request.Headers["X-Tenant"].ToString();
        var key = $"content:{slug}";
        if (_cache.TryGetValue(key, out ContentDto? cached))
            return Ok(cached);

        var draft = preview || Request.Headers.ContainsKey("X-Preview");
        var content = await _reader.ReadAsync(
            tenant, slug, language ?? "en", draft, ct);

        if (content is null)
            return NotFound();

        _cache.Set(key, content, TimeSpan.FromHours(2));
        Response.Headers.CacheControl = "public,max-age=3600";
        Response.Headers.ETag = $"\"{content.Version}\"";
        _logger.LogInformation(
            "Content {Slug} returned for {Tenant}: {Body}",
            slug, tenant, JsonSerializer.Serialize(content));
        return Ok(content);
    }
}

public interface IContentReader
{
    Task<ContentDto?> ReadAsync(
        string tenant, string slug, string language,
        bool includeDraft, CancellationToken ct);
}

public sealed record ContentDto(
    string Slug, string Version, string Html,
    bool IsPublished);
```

## Kết quả code review tham khảo

### [Critical] — Preview được bật bằng dữ liệu do client tự khai báo

**Vấn đề:** Query `preview=true` hoặc header `X-Preview` cho phép đọc draft mà không xác thực quyền editor.  
**Tại sao xảy ra:** API tin input không đáng tin thay vì identity/authorization server-side.  
**Ảnh hưởng production:** Rò rỉ chiến dịch chưa công bố, nội dung nội bộ.  
**Cách sửa:** Preview endpoint riêng với authentication và policy; CMS reader cũng phải enforce authorization.

### [Critical] — Cache key không tách tenant, locale và visibility

**Vấn đề:** `content:{slug}` gộp mọi representation.  
**Tại sao xảy ra:** Key bỏ qua các chiều quyết định kết quả.  
**Ảnh hưởng production:** Cross-tenant leak, sai ngôn ngữ, draft xuất hiện trong public response.  
**Cách sửa:** Tách public/preview hoàn toàn; public key gồm trusted tenant, locale, slug và revision hoặc generation.

### [High] — Preview có thể bị CDN cache công khai

**Vấn đề:** `Cache-Control: public` được dùng cho cả draft.  
**Tại sao xảy ra:** Chính sách cache không phân biệt nội dung nhạy cảm.  
**Ảnh hưởng production:** Một lần preview có thể lan sang người dùng khác tùy CDN configuration.  
**Cách sửa:** Preview dùng `private, no-store`, bypass CDN và cache nội bộ shared.

### [High] — Tenant lấy trực tiếp từ header

**Vấn đề:** `X-Tenant` không được ràng buộc với identity/hostname đáng tin.  
**Tại sao xảy ra:** Client có thể tự nhận tenant khác.  
**Ảnh hưởng production:** Truy cập dữ liệu cross-tenant ngay cả khi cache tắt.  
**Cách sửa:** Resolve tenant từ authenticated claims hoặc verified host mapping; authorize membership.

### [High] — Không có invalidation sau publish/unpublish

**Vấn đề:** TTL 2 giờ ở memory và 1 giờ tại edge không gắn với lifecycle nội dung.  
**Tại sao xảy ra:** Không có publish event, revision hoặc purge workflow.  
**Ảnh hưởng production:** Nội dung cũ còn hiển thị, unpublish không được thu hồi kịp.  
**Cách sửa:** Event-driven invalidation, versioned keys và CDN purge; xác định SLA freshness, đặc biệt cho unpublish.

### [Medium] — ETag thiếu phạm vi representation

**Vấn đề:** Chỉ dùng `Version`, không xét tenant/locale/visibility.  
**Tại sao xảy ra:** Identifier version chưa chắc global-unique.  
**Ảnh hưởng production:** Conditional caching có thể tái sử dụng sai representation nếu mở rộng xử lý 304.  
**Cách sửa:** Tạo ETag theo immutable representation identity; xử lý `If-None-Match` nhất quán.

### [Medium] — Cache hit bỏ qua response cache headers

**Vấn đề:** Return sớm trước khi thiết lập headers.  
**Tại sao xảy ra:** Header logic chỉ chạy khi cache miss.  
**Ảnh hưởng production:** Edge behavior không đồng nhất theo trạng thái origin cache.  
**Cách sửa:** Đặt chính sách response nhất quán trước return.

### [Medium] — Log toàn bộ HTML

**Vấn đề:** Structured log chứa toàn bộ content body.  
**Tại sao xảy ra:** Logging payload thay vì metadata.  
**Ảnh hưởng production:** Rò rỉ draft/PII, tăng chi phí ingest.  
**Cách sửa:** Log content ID, tenant pseudonymous ID, revision, mode và correlation ID.

### [Medium] — Memory cache per-instance thiếu phối hợp

**Vấn đề:** Mỗi replica giữ bản riêng và có thể bị stampede.  
**Tại sao xảy ra:** Invalidation không broadcast; nhiều miss cùng đọc CMS.  
**Ảnh hưởng production:** Staleness không đồng đều và CMS overload.  
**Cách sửa:** Cache strategy có generation/version và bounded refresh; đo trước khi thêm distributed cache.

## Phiên bản đề xuất

Ví dụ dưới đây dùng abstraction nội bộ; `IPublicContentStore` chỉ trả published content, `ITenantResolver` xác minh tenant và `IContentRevisionProvider` cung cấp generation đã được đồng bộ sau publish. Preview nên là controller riêng có policy và bypass CDN.

```csharp
[ApiController]
[Route("api/public/content")]
public sealed class PublicContentController(
    IPublicContentStore store,
    ITenantResolver tenants,
    IContentRevisionProvider revisions,
    IMemoryCache cache) : ControllerBase
{
    [HttpGet("{slug}")]
    public async Task<IActionResult> Get(
        string slug, [FromQuery] string language = "en",
        CancellationToken ct = default)
    {
        var tenant = await tenants.ResolveVerifiedAsync(HttpContext, ct);
        if (tenant is null) return Forbid();

        var locale = language.Trim().ToLowerInvariant();
        if (!SupportedLocales.Contains(locale)) return BadRequest();
        var revision = await revisions.GetGenerationAsync(
            tenant.Id, ct);
        var key = $"published:{tenant.Id}:{locale}:{slug}:{revision}";
        var item = await cache.GetOrCreateAsync(key, async entry =>
        {
            entry.AbsoluteExpirationRelativeToNow =
                TimeSpan.FromMinutes(2);
            return await store.ReadPublishedAsync(
                tenant.Id, slug, locale, ct);
        });

        Response.Headers.CacheControl = "public,max-age=60";
        if (item is null) return NotFound();
        Response.Headers.ETag =
            $"\"{tenant.Id}-{locale}-{item.Version}\"";
        return Ok(item);
    }

    private static readonly HashSet<string> SupportedLocales =
        new(StringComparer.Ordinal) { "en", "vi" };
}

[Authorize(Policy = "CmsEditor")]
[ApiController]
[Route("api/editor/preview")]
public sealed class PreviewController(
    IAuthorizedPreviewReader reader,
    ITenantResolver tenants) : ControllerBase
{
    [HttpGet("{slug}")]
    public async Task<IActionResult> Get(
        string slug, string language = "en",
        CancellationToken ct = default)
    {
        Response.Headers.CacheControl = "private,no-store";
        var tenant = await tenants.ResolveVerifiedAsync(
            HttpContext, ct);
        if (tenant is null) return Forbid();
        var draft = await reader.ReadAuthorizedDraftAsync(
            User, tenant.Id, slug, language, ct);
        return draft is null ? NotFound() : Ok(draft);
    }
}
```

**Điều kiện triển khai:** CDN phải bypass `/api/editor/*`, không cache authenticated preview; cache key public phải phân biệt tenant theo trusted host/path, không theo header chưa được CDN đưa vào key. Generation cần tăng khi publish/unpublish và purge edge tương ứng. Nếu freshness SLA chặt, TTL chỉ là fallback, không thay thế invalidation. `GetOrCreateAsync` không tự bảo đảm single-flight trên mọi miss đồng thời.

## Giải thích thiết kế sau khi sửa

Public read model không có khả năng truy cập draft; preview sử dụng policy và authorization ở tầng reader. Generation khiến memory cache mới không dùng key cũ, trong khi CDN purge xử lý bản đã phát ra edge. Không cần microservices hay Redis nếu origin tải thấp và invalidation đã đáng tin cậy.

## Trade-offs

Generation lookup tăng một dependency mỗi request nếu không cache hợp lý; CDN purge bất đồng bộ có khoảng stale; `no-store` làm preview tốn origin; versioned keys tiêu thụ bộ nhớ cho đến khi hết TTL. Nếu CMS cần unpublish tức thì, phải xác định hành vi khi purge thất bại và cân nhắc edge TTL rất ngắn hoặc denylist.

## Cách kiểm thử

1. Security integration: anonymous và editor không thuộc tenant không thể đọc draft, kể cả tự thêm header.
2. Cross-tenant/locale: cùng slug, hai tenant và hai locale không trả lẫn nội dung dưới concurrent load.
3. Publish/unpublish: generation thay đổi, edge purge được gọi, stale window nằm trong SLA.
4. Failure injection: CDN purge thất bại; hệ thống alert và thực hiện retry/reconcile.
5. Load test: nhiều cache miss cùng lúc; đo CMS read count, p95 và memory usage.

## Quan sát trong production

Structured logs gồm content ID, tenant hash, locale, published revision, cache layer, request correlation; không ghi HTML. Theo dõi CDN hit/miss, purge latency/failure, origin p95, CMS read rate, tỷ lệ revision mismatch và cảnh báo bất kỳ draft response nào trên public path.

## Câu hỏi phỏng vấn mở rộng

1. Nếu một nội dung bị unpublish vì lý do pháp lý, thiết kế SLA thu hồi toàn cầu thế nào?
2. Khi CDN không hỗ trợ purge theo tag, so sánh versioned URL và TTL ngắn.
3. Khi nào distributed cache thực sự tốt hơn local memory cache?

```vue
<script setup lang="ts">
import { ref, watch, onMounted } from 'vue';

type Customer = {
  id: string;
  name: string;
  email: string;
  note: string;
};

const query = ref('');
const customers = ref<Customer[]>([]);
const loading = ref(false);
const error = ref('');
const selected = ref<Customer | null>(null);

async function search() {
  loading.value = true;
  error.value = '';
  const token = localStorage.getItem('access_token');
  const response = await fetch(
    '/api/customers/search?q=' + encodeURIComponent(query.value),
    { headers: { Authorization: 'Bearer ' + token } }
  );
  const data = await response.json();
  customers.value = data.items;
  loading.value = false;
}

watch(query, () => {
  search().catch(e => { error.value = String(e); });
});

onMounted(() => {
  const saved = sessionStorage.getItem('lastCustomers');
  if (saved) customers.value = JSON.parse(saved);
});

function choose(customer: Customer) {
  selected.value = customer;
  sessionStorage.setItem(
    'lastCustomers', JSON.stringify(customers.value));
}
</script>

<template>
  <input v-model="query" placeholder="Search customers" />
  <span v-if="loading">Loading...</span>
  <p v-if="error">{{ error }}</p>
  <ul>
    <li v-for="customer in customers" :key="customer.id">
      <button @click="choose(customer)">
        {{ customer.name }} — {{ customer.email }}
      </button>
    </li>
  </ul>
  <article v-if="selected">
    <h3>{{ selected.name }}</h3>
    <p>{{ selected.note }}</p>
  </article>
</template>
```

## Kết quả code review tham khảo

### [High] — Stale response ghi đè kết quả mới

**Vấn đề:** Request cũ có thể hoàn tất sau request mới và ghi đè `customers`.  
**Tại sao xảy ra:** Không có cancellation hoặc request generation guard.

### [High] — Dữ liệu khách hàng lưu không ràng buộc session identity

**Vấn đề:** `sessionStorage` chứa toàn bộ customer records và được load lại không kiểm tra user/tenant.  
**Tại sao xảy ra:** Browser storage được xem như cache tin cậy.  
**Ảnh hưởng production:** Rò rỉ PII trong cùng tab khi đổi account; tồn tại sau logout nếu không clear.  
**Cách sửa:** Không lưu PII; clear state khi identity thay đổi và khi logout.

### [High] — Access token trong localStorage

**Vấn đề:** Token có thể bị đọc bởi JavaScript khi XSS xảy ra.  
**Tại sao xảy ra:** Long-lived bearer credential lưu trong web-accessible storage.  
**Ảnh hưởng production:** Token theft và account compromise.  
**Cách sửa:** Đánh giá BFF + HttpOnly Secure SameSite cookie, CSRF protection; hoặc memory-only token với threat model rõ ràng.

### [Medium] — PII trong query string

**Vấn đề:** Email/search term nằm trong URL.  
**Tại sao xảy ra:** GET query được dùng cho dữ liệu nhạy cảm.  
**Ảnh hưởng production:** Có thể xuất hiện trong server/proxy access logs, monitoring, browser history tùy cách sử dụng.  
**Cách sửa:** POST JSON search với no-store và redaction; vẫn phải bảo vệ logs/backend.

### [Medium] — Không kiểm tra HTTP status

**Vấn đề:** JSON lỗi 401/500 có thể được coi là kết quả hợp lệ.  
**Tại sao xảy ra:** `fetch` không throw khi HTTP non-2xx.  
**Ảnh hưởng production:** UI rỗng/sai hoặc runtime exception khó hiểu.  
**Cách sửa:** Kiểm tra `response.ok`, xử lý 401/403 và schema validation.

### [Medium] — Loading và error không gắn với request hiện hành

**Vấn đề:** Request cũ có thể tắt spinner hoặc set error của request mới; lỗi không reset loading.

**Ảnh hưởng production:** UX sai trạng thái, lỗi bị che.  
**Cách sửa:** Request sequence + `try/catch/finally` có guard.

### [Medium] — Không debounce và không abort khi unmount

**Vấn đề:** Mỗi ký tự tạo request; request vẫn chạy khi component rời trang.  
**Tại sao xảy ra:** Watcher không quản lý lifecycle.  
**Ảnh hưởng production:** API load cao, bandwidth lãng phí.  
**Cách sửa:** Debounce, AbortController, cleanup.

### [Medium] — Selected object không reset theo result/identity

**Ảnh hưởng production:** Hiển thị thông tin không còn thuộc context hiện tại.  
**Cách sửa:** Clear selection khi query/session thay đổi, revalidate detail trên backend trước thao tác nhạy cảm.

## Phiên bản đề xuất

Ví dụ dùng BFF cookie session; server phải cấu hình cookie, CSRF token, authorization và `Cache-Control: no-store`. `sessionVersion` được tăng bởi application auth store khi login/logout/tenant switch; component nhận prop này.

```vue
<script setup lang="ts">
import { ref, watch, onBeforeUnmount } from 'vue';

type CustomerSummary = { id: string; name: string; email: string };
const props = defineProps<{ sessionVersion: number }>();
const query = ref('');
const customers = ref<CustomerSummary[]>([]);
const selectedId = ref<string | null>(null);
const loading = ref(false);
const error = ref('');
let controller: AbortController | undefined;
let timer: ReturnType<typeof setTimeout> | undefined;
let generation = 0;

function reset() {
  generation++;
  controller?.abort();
  clearTimeout(timer);
  customers.value = [];
  selectedId.value = null;
  loading.value = false;
  error.value = '';
}

watch(() => props.sessionVersion, reset);

watch(query, value => {
  reset();
  const text = value.trim();
  if (text.length < 2) return;
  const mine = generation;
  timer = setTimeout(async () => {
    if (mine !== generation) return;
    const request = new AbortController();
    controller = request;
    loading.value = true;
    try {
      const response = await fetch('/api/customers/search', {
        method: 'POST',
        credentials: 'same-origin',
        headers: {
          'Content-Type': 'application/json',
          'X-CSRF-Token': readCsrfToken()
        },
        body: JSON.stringify({ query: text, limit: 20 }),
        signal: request.signal,
        cache: 'no-store'
      });
      if (!response.ok) throw new Error(
        response.status === 401 ? 'Session expired' : 'Search failed');
      const body: unknown = await response.json();
      const items = parseCustomerSummaries(body);
      if (mine === generation) customers.value = items;
    } catch (e) {
      if (mine === generation && !request.signal.aborted)
        error.value = 'Không thể tìm kiếm. Vui lòng thử lại.';
    } finally {
      if (mine === generation) loading.value = false;
    }
  }, 250);
});
onBeforeUnmount(reset);
```

## Giải thích thiết kế sau khi sửa

Sequence guard đảm bảo chỉ request thuộc query/session hiện tại được cập nhật state; abort giảm công việc nhưng không thay thế guard. Debounce giảm request rate. Không lưu PII trong browser storage. Backend vẫn là nguồn quyết định authorization; chọn customer ID không cấp quyền truy cập dữ liệu.

## Trade-offs

POST search khó cache bằng CDN hơn GET; BFF cần CSRF defense và session infrastructure; debounce làm tăng độ trễ cảm nhận khoảng 250 ms; abort không đảm bảo backend đã dừng xử lý. Với search không chứa PII và public data, GET có thể phù hợp hơn; lựa chọn dựa trên threat model.

## Cách kiểm thử

1. Playwright: delay response của query A, trả B trước; UI chỉ hiển thị B.
2. Playwright: logout/login user khác trong cùng tab; không còn dữ liệu hay selected customer cũ.
3. API integration: 401/403/500 trả error state phù hợp, không parse thành customer list.
4. Load test: gõ 20 ký tự liên tục, đo request rate và backend concurrency.
5. Security test: CSRF token invalid bị từ chối; user A không thể truy cập customer thuộc tenant B.

## Quan sát trong production

Đo search p95/p99, request cancellation rate, HTTP status, debounce effectiveness và rate-limit rejection; trace từ browser tới API bằng correlation ID. Không log raw query, email, token hoặc response body; dùng query length, sanitized category và tenant hash khi cần.

## Câu hỏi phỏng vấn mở rộng

1. Khi frontend dùng React Query hoặc TanStack Query, còn cần generation guard ở đâu?
2. Nếu search API trả cursor và người dùng cuộn vô hạn, làm sao tránh trộn pages của hai query?
3. Khi BFF session hết hạn giữa chừng, frontend và backend phối hợp refresh/redirect ra sao?

## Kiến thức trọng tâm

Cache key phải bao gồm mọi chiều ảnh hưởng representation và không được vượt qua authorization boundary. Preview là dữ liệu nhạy cảm cần policy riêng và không được public-cache.
