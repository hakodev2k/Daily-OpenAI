# Code Review Challenge 1 — EF Core concurrency trong payment callback

**Chủ đề:** Concurrency, transaction, idempotency
**Độ khó:** Senior

## Bối cảnh

Hệ thống thương mại điện tử nhận payment callback từ bên thứ ba. API chạy nhiều instance trên Azure. Production phát hiện duplicate transaction và inventory bị cập nhật sai khi provider retry.

## Đoạn code cần review

```csharp
public async Task ConfirmPaymentAsync(Guid orderId, CancellationToken ct)
{
    var order = await _db.Orders.FirstAsync(x => x.Id == orderId, ct);

    if (order.Status == OrderStatus.Paid)
        return;

    order.Status = OrderStatus.Paid;

    await _db.PaymentTransactions.AddAsync(new PaymentTransaction
    {
        OrderId = orderId,
        CreatedAt = DateTime.UtcNow
    }, ct);

    await _inventoryService.ReserveAsync(order.ProductId, ct);
    await _db.SaveChangesAsync(ct);
}
```

## Gợi ý

- Kiểm tra race condition.
- Xem xét idempotency key, transaction boundary và optimistic concurrency.

## Kết quả code review tham khảo

- Thiếu concurrency control khiến nhiều callback cùng xử lý.
- Thiếu idempotency khiến duplicate payment.
- External call nằm trong flow database chưa đảm bảo consistency.

## Code đề xuất

Dùng transaction cho state transition, unique constraint cho payment id, concurrency token cho Order và workflow retry riêng cho inventory.

# Code Review Challenge 2 — Background worker mất kiểm soát lifecycle

**Chủ đề:** async/await, cancellation, resource lifetime
**Độ khó:** Senior

## Bối cảnh

Worker đọc RabbitMQ để gửi email. Khi traffic tăng, memory tăng và shutdown không graceful.

## Đoạn code cần review

```csharp
protected override async Task ExecuteAsync(CancellationToken stoppingToken)
{
    while (true)
    {
        var message = await _client.ReceiveAsync();

        _ = Task.Run(async () =>
        {
            await _sender.SendAsync(message);
            await _client.AckAsync(message.Id);
        });
    }
}
```

## Gợi ý

- Kiểm tra fire-and-forget.
- Cần bounded queue, controlled concurrency và graceful shutdown.

---

**Hãy tự review đoạn code trước khi xem phần phân tích bên dưới.**

## Kết quả code review tham khảo

- Bỏ qua cancellation.
- Không quản lý task lifecycle.
- Không giới hạn concurrency.
- Exception có thể bị mất.
