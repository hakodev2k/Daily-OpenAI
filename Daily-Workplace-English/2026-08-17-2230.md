# Daily Workplace English — Ngày 45

- **Ngày:** 17/08/2026 (UTC+7)
- **Tình huống công việc:** Báo cáo blocker khi tích hợp Microsoft Graph API
- **Kỹ năng giao tiếp chính:** Giải thích blocker, nêu tác động và đề xuất bước tiếp theo
- **Thời gian học:** 20 phút
- **Độ khó:** Lower-intermediate

## 1. Tình huống hôm nay

Bạn đang phát triển một tính năng backend .NET sử dụng Microsoft Graph API để đồng bộ dữ liệu lịch. Sau khi deploy lên môi trường test, API trả về lỗi authentication vì permission hoặc token configuration chưa đúng.

Người liên quan gồm bạn, Technical Lead và team phụ trách Azure configuration. Bạn cần báo cáo tình trạng mà không chỉ nói "it is broken". Mục tiêu là giải thích vấn đề, ảnh hưởng, phần đã kiểm tra và hỗ trợ cần thiết.

## 2. Bạn cần nói gì?

- Mô tả vấn đề hiện tại.
- Nói rõ bạn đã kiểm tra những gì.
- Giải thích tác động đến timeline.
- Yêu cầu hỗ trợ cụ thể.
- Cam kết bước cập nhật tiếp theo.

## 3. Đoạn hội thoại

**Developer:** I have a blocker with the Microsoft Graph integration. The API call is failing because the application does not have the required permission.

Hiện tại tôi đang bị block ở phần tích hợp Microsoft Graph. API call thất bại vì application chưa có permission cần thiết.

**Lead:** What have you checked so far?

Bạn đã kiểm tra những gì rồi?

**Developer:** I have verified the code flow and token generation. The issue seems to be related to Azure configuration rather than the implementation.

Tôi đã kiểm tra flow code và việc tạo token. Có vẻ vấn đề liên quan đến Azure configuration hơn là phần code.

**Lead:** What do you need from the team?

Bạn cần team hỗ trợ gì?

**Developer:** Could the Azure team help verify the application permissions? Once it is updated, I can continue testing the feature.

Team Azure có thể hỗ trợ kiểm tra application permissions không? Khi cập nhật xong tôi có thể tiếp tục test feature.

## 4. Các cụm từ quan trọng

### "I have a blocker with..."
- Nghĩa: Tôi đang gặp blocker với...
- Dùng khi báo cáo vấn đề ngăn công việc tiếp tục.
- Ví dụ: I have a blocker with the deployment pipeline.

### "I have verified..."
- Nghĩa: Tôi đã xác nhận/kiểm tra...
- Dùng để thể hiện đã điều tra trước khi nhờ hỗ trợ.
- Ví dụ: I have verified the database connection settings.

### "The issue seems to be related to..."
- Nghĩa: Vấn đề có vẻ liên quan đến...
- Dùng khi chưa chắc chắn 100%.
- Ví dụ: The issue seems to be related to caching.

### "Could you help verify...?"
- Nghĩa: Bạn có thể giúp xác nhận...?
- Dùng để nhờ hỗ trợ lịch sự.
- Ví dụ: Could you help verify the environment settings?

### "Once it is updated, I can continue..."
- Nghĩa: Khi nó được cập nhật, tôi có thể tiếp tục...
- Dùng để mô tả dependency.
- Ví dụ: Once the migration is completed, we can test the API.

## 5. Từ vựng trong tình huống

- **blocker** /ˈblɒkər/: danh từ, trở ngại
  - Example: This permission issue is a blocker.
  - Collocation: remove a blocker

- **permission** /pərˈmɪʃən/: quyền truy cập
  - Example: The application needs additional permissions.
  - Collocation: grant permission

- **configuration** /kənˌfɪɡjəˈreɪʃən/: cấu hình
  - Example: The issue is related to configuration.
  - Collocation: environment configuration

- **verify** /ˈverɪfaɪ/: xác minh
  - Example: We need to verify the settings.
  - Collocation: verify a result

## 6. Mẫu câu cần nhớ

**Present perfect để mô tả việc đã kiểm tra:**

Structure:

I have + past participle + object.

Dùng khi nói về hành động đã hoàn thành nhưng kết quả vẫn liên quan hiện tại.

Ví dụ:

- I have checked the logs.
- I have verified the configuration.

Lỗi thường gặp:

Không dùng "I checked" khi muốn nhấn mạnh kết quả kiểm tra hiện tại.

## 7. Cách nói tự nhiên hơn

### Chưa tự nhiên
"It is broken."

### Tự nhiên hơn
"The API call is failing due to a permission issue."

Giải thích: Câu thứ hai mô tả nguyên nhân kỹ thuật rõ hơn.

### Chưa tự nhiên
"Fix this permission."

### Tự nhiên hơn
"Could you help update the required permission?"

Giải thích: Đây là cách yêu cầu phối hợp chuyên nghiệp hơn.

## 8. Phát âm và luyện nói

Cụm cần luyện:

- **I have a blocker with...**
  - Nhấn mạnh: blocker
  - Ngắt: I have a blocker / with the integration.

- **The issue seems to be related to...**
  - Nhấn mạnh: issue, related

Shadowing:

I have a blocker with the current integration.
I have verified the code flow and configuration.
The issue seems to be related to permissions.
Could you help verify the Azure settings?

## 9. Bài tập nhanh

1. Điền từ: I have a ______ with the deployment process.
2. Chọn câu chuyên nghiệp hơn:
   - A. Fix this now.
   - B. Could you help investigate this issue?
3. Hoàn thành: I have verified ______.
4. Viết lại: "The API is broken."

## 14. Tóm tắt cần ghi nhớ

### 3 câu nên nhớ

1. I have a blocker with the current task.
2. I have verified the implementation and configuration.
3. Could you help investigate this issue?

### Lỗi cần tránh

- Chỉ nói "It doesn't work" mà không nói nguyên nhân.
- Dùng câu mệnh lệnh khi nhờ team khác hỗ trợ.
- Không nói rõ mình đã kiểm tra gì.

### Thử thách hôm nay

Trong cuộc họp hoặc chat công việc, hãy dùng một câu theo mẫu:

"I have a blocker with ____. I have checked ____. Could you help verify ____?"
