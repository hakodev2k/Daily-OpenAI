Issue đang **open**, labels gồm `bug`, `area:providers`, `area:desktop-ui`, `priority:high`, chưa có assignee/comment; tìm kiếm tại thời điểm quét chưa thấy open PR khớp issue.  
Source: https://github.com/FerroxLabs/wayland/issues/1039

**Analysis:** đây là một design lesson rất đáng áp dụng cho agent platforms: **credential availability không được đồng nghĩa với execution authorization**. Việc một process có thể nhìn thấy key không có nghĩa backend được phép tự dùng key đó.

Một kiến trúc an toàn hơn nên tách:
- credential store;
- explicit provider selection;
- provider allowlist per agent/runtime;
- resolved-cost/provider visibility trước execution;
- audit record cho provider/model thực tế đã dùng.

Điều này cũng áp dụng trực tiếp cho Cursor/Claude Code/Codex orchestration, MCP servers và các agent runtime tự build.

**Who is affected:** user kết nối nhiều provider credentials và sử dụng Nano/related desktop-agent flows.

**Compatibility/migration concern:** policy nào đúng vẫn chưa được maintainer quyết định: không export credential trừ khi explicitly configured, chỉ hiển thị resolved provider, hoặc làm cả hai. Vì vậy chưa nên nhảy vào code ngay.

**Security/operational risk:** vấn đề chính là billing/trust và privilege-by-environment; issue có nhắc một report billing trước đó nhưng chưa xác minh rằng hai case cùng root cause.

**Should I test now?** Chỉ test trong sandbox với API key có hard spending limit hoặc disposable credential. Không nên thử bằng production key.
