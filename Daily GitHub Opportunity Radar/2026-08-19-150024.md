## 5. Tool I Can Apply Today

**Tool:** `skil`  
**Problem it solves:** Pre-install/pre-merge inspection của AI agent skills, embedded code, MCP config và declared capabilities.  
**Relevant workflow:** Codex/Cursor/Claude-style skills, MCP integration, GitHub Actions, reusable AI role packages.  
**Adoption difficulty:** **Moderate**  
**Production readiness:** **Experimental / Early**

**Where it fits into workflow:**
- Trước khi đưa third-party skill vào `.agents/skills` hoặc equivalent directory.
- Trong CI của repo chứa shared skills/rules/scripts.
- Trước khi publish một AI role package có `SKILL.md`, scripts, hooks hoặc MCP manifests.

**What it could improve:**
- Thay manual review thuần túy bằng repeatable lint/static scan.
- Có SARIF để đưa finding vào GitHub security/review workflow.
- Có policy/attestation primitives để dần xây trusted-skill pipeline.

**Integration approach:**
- Local: `skil lint` + `skil scan --static-only`.
- GitHub Actions: install tool, scan skill directory, output SARIF/JSON.
- Với `.NET` project: tool không cần rewrite app; nó đứng ngoài như CI/security utility.
- Với MCP: dùng MCP registry scan và checks cho wildcard/tool-description/mutable-tool identity theo README.

**Required permissions / data access:** Static local scan chỉ cần read access tới skill artifact. OSV, remote scan hoặc semantic providers là opt-in và có network/API key requirements riêng.

**Privacy/security concerns:**
- Không bật semantic provider-backed scan cho proprietary skill code trước khi xác minh data handling/provider policy.
- Không dùng scan result như bằng chứng tuyệt đối rằng skill an toàn; static analysis vẫn có blind spots.

**Maintenance burden:** Moderate; pin version trong CI và review rule changes vì analyzer behavior có thể thay đổi nhanh ở project mới.

### Smallest proof of concept — 30–60 phút

- Chọn 3 skills đang dùng: một clean, một có shell script, một có MCP config.
- Chạy `lint`, `validate`, `scan --static-only`.
- Export SARIF và xem findings có chỉ ra actionable location/rule không.
- Ghi false positives để quyết định tool có đáng đưa vào CI hay chỉ dùng manual audit.
