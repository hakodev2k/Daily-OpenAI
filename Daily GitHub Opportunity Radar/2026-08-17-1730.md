## 3. Important Release or Update

### beacon-trader — PR #219 `Every image records the commit it was built from, not one of five`

**Release date:** 17/08/2026  
**Release type:** Integration / Infrastructure  
**Action:** **Investigate**

**Confirmed facts:** Issue #218 ghi nhận `BEACON_GIT_SHA` bị unset trong `api`, `executor`, `monitor`, `telegram` dù build command truyền `GIT_SHA`. Root cause là chỉ `services/replay/Dockerfile` khai báo `ARG GIT_SHA` và compose chỉ pass build arg cho replay/replay-worker. PR #219 được mở lúc 17:26 UTC+7, thêm `ARG/ENV` cho bốn image, thêm compose args và một guard test. PR báo full suite **1312 passed, 2 skipped** và đo một rebuild chỉ thay SHA giữ **6 cached layers**, elapsed ~1s. PR hiện vẫn open, chưa merge.  
Sources: https://github.com/magedzamzam/beacon-trader/issues/218 · https://github.com/magedzamzam/beacon-trader/pull/219

**Analysis:** Đây là pattern DevOps tốt: provenance không chỉ là biến môi trường mà cần contract test để mọi future service có `build:` cũng phải wiring metadata. Việc đặt `ARG/ENV` sau dependency/source layers giúp tránh phá Docker cache không cần thiết.

**Opportunity:** áp dụng cùng pattern cho các app .NET multi-container: inject commit SHA/build number vào image, expose qua `/health` hoặc `/version`, rồi verify sau deploy bằng smoke test.

**Risk or uncertainty:** PR chưa merge; `BEACON_GIT_SHA` mới chỉ “available”, chưa được surface ở health endpoint. Không nên coi đây là production behavior đã hoàn tất.
