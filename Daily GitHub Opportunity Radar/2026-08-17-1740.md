Repository: https://github.com/ecotask-network/EcoTask-backend

**Analysis:** Đây là bug rất gần với backend engineering thực tế: stable ordering, keyset pagination, backward-compatible cursor format và test boundary. Kỹ năng chuyển trực tiếp sang EF Core/SQL Server/PostgreSQL.

Một .NET equivalent thường cũng cần sort theo `(CreatedAt, Id)` và cursor predicate tương đương:
