### Cloudflare Computer 0.2.1 — sync wedge report

**Release date:** Issue filed 17/08/2026 20:44 UTC+7  
**Release type:** Reliability / Data integrity  
**Action:** Investigate  

**Confirmed facts:** [Issue #107](https://github.com/cloudflare/computer/issues/107) báo cáo `@cloudflare/computer` 0.2.1 có thể bị wedge sync ở cả pull và push khi child entry được apply trước parent directory. Report có reproduction trên Workers + Containers production, nêu trạng thái `sync.status: "pending"` lặp lại, trường hợp replacement container khiến mọi `runtime.exec` bị block, cùng hai workaround đã được tác giả kiểm chứng.

**Analysis:** Đây là lỗi đáng học với bất kỳ agent runtime nào có writable workspace lâu dài. Nếu agent tạo file nền ngoài execution bracket, metadata/revision ordering có thể phá giả định parent-before-child. Một sync layer cho agent nên coi filesystem ordering là partial-order problem, không chỉ là sorted stream problem.

**Opportunity:** Dùng issue này để xây checklist cho persistent agent workspace: topological parent ordering, idempotent retry, recovery channel độc lập với normal exec, observable stalled state, và fuzz test cho rename/create/delete ordering.

**Risk or uncertainty:** Root cause trong issue được tác giả ghi rõ là hypothesis phù hợp với quan sát, chưa phải maintainer-confirmed diagnosis. Không nên khẳng định fix cuối cùng phải là `mkdir -p` hay đổi sort order trước khi maintainer xác nhận invariant mong muốn.
