### get-convex/convex-agent-plugins — issue #27: Windows `beforeShellExecution` hook

**Update date:** 2026-08-19  
**Release type:** **Bug / Integration**  
**Action:** **Investigate**  
**Issue:** https://github.com/get-convex/convex-agent-plugins/issues/27

**Confirmed facts:**
- Reporter reproduces trên Windows 11 + Cursor.
- Plugin hook cho `git commit` gọi `./scripts/pre-commit-checks.sh`.
- Trên môi trường reporter, Cursor mở `pre-commit-checks.sh` như editor tab thay vì chạy hook headlessly.
- Issue liên hệ root cause với shell-script invocation và chỉ ra issue #8 đã nói về Windows hook failure trước đó.
- Workaround được reporter nêu là disable hook trong Cursor Settings hoặc không dùng commit gate này.

**Analysis:**
- Đây là lỗi rất đáng chú ý cho bất kỳ ai thiết kế `hooks`, vì một hook “works on macOS/Linux” chưa đủ nếu workflow target developer Windows.
- Với agent workflows, failure còn nguy hiểm hơn UX thông thường: guard tưởng đang chạy nhưng thực tế có thể không enforce pre-commit checks.

**Opportunity:**
- Khi viết hooks riêng cho Cursor/Codex/Claude-style tooling, ưu tiên Node/.NET executable hoặc explicit shell invocation thay vì giả định `.sh` tự chạy trên Windows.
- Thêm CI matrix Windows/Linux cho hook runner.

**Risk or uncertainty:**
- Đây là issue report chưa phải maintainer-confirmed fix.
- Không nên kết luận mọi Cursor Bash hook trên Windows đều hỏng; report này gắn với plugin và invocation cụ thể.
