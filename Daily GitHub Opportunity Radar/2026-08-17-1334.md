- có breaking change ở experimental functional workflow API: workflow definition cần được build thành stateful workflow instance trước khi run/adapt thành agent;
- có nhiều fix quanh compaction, approvals/replay, skills discovery, transcript persistence và state handling.

Source: https://github.com/microsoft/agent-framework/releases/tag/python-1.14.0

**Analysis:** Đây là một release đáng học về kiến trúc agent hơn là chỉ dependency upgrade. Hooks, checkpoint/resume, session cleanup và approval state đều là những primitive cần thiết khi agent chuyển từ “single prompt → answer” sang long-running workflows có retry, interruption và human approval.

**Opportunity:** Dựng một sandbox nhỏ để mô phỏng `plan → execute → checkpoint → interrupt → resume`, sau đó so sánh với cách bạn đang thiết kế QA/research/coding agent loops.

**Risk or uncertainty:** Đây là Python release, không phải .NET release.
