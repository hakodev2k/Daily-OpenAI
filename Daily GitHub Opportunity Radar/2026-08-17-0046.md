**Maturity:** Early  
**Relevance to me:** High  

**Confirmed facts:** README mô tả `mcp-guard` là scanner zero-dependency cho MCP server configurations. Nó có năm nhóm rule chính: hardcoded secrets, shell injection, remote fetch-and-execute, broad filesystem scope và unpinned dependencies. Tool hỗ trợ auto-discovery cho nhiều MCP clients gồm Claude Desktop, Claude Code, Cursor, VS Code/Cline/Roo Code/Continue/Windsurf; có JSON output và `--fail-on` để dùng trong CI. Source: https://github.com/flickzoz/mcp-guard/blob/main/README.md

**Analysis:** Đây là loại tool nhỏ nhưng có leverage cao vì MCP configs thường được copy từ README/community lists và có quyền chạy process trên máy developer. Với workflow AI coding, scan config trước khi thêm MCP server mới là một guardrail rẻ hơn nhiều so với xử lý secret leak hoặc command execution không mong muốn sau đó.

**Opportunity:** Dùng như pre-commit/CI check cho `.cursor/mcp.json`, `.claude/mcp.json`, `.vscode/mcp.json` hoặc shared team config; sau đó đánh giá false-positive/false-negative bằng một tập config tự tạo.

**Risk or uncertainty:** Repo còn rất mới và rule set thiên về static heuristics. Số stars/forks ban đầu không chứng minh scanner đã được audit rộng rãi. Nó không thay thế sandboxing, OS permissions, secret management, MCP server review hay runtime authorization.

- **What to test:** tạo một thư mục thử nghiệm có 3 MCP configs: một config bình thường, một config dùng `bash -c`/broad filesystem path, một config chứa unpinned `npx`/`uvx` dependency; chạy scan dạng JSON và `--fail-on high`.
- **Expected result:** tool phân loại được các risk patterns và trả non-zero exit code khi severity đạt threshold.
- **Worth further investigation if:** findings đủ ổn định để đưa vào GitHub Actions mà không tạo nhiều false positives, và rule output đủ cụ thể để developer sửa config nhanh.
