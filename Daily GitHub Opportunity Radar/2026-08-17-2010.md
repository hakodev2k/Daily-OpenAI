## 6. Product or Learning Opportunity

### Developer tool idea — Agent Permission & Billing Boundary Linter

**Problem:** Agent platforms thường truyền credential/tool access theo environment hoặc global config, trong khi intent của người dùng lại là “key này dành cho provider/agent A”. Đây là gap giữa availability và authorization, được thấy rõ trong Wayland #1039.

**Intended user:** Dev team xây AI coding tools, MCP clients, internal agents, multi-provider orchestration.

**Why opportunity may exist:** Provider routing, secret inheritance, MCP tool loading và fallback chain ngày càng phức tạp; các lỗi trust thường không phải syntax bug mà là policy/config bug.

**Smallest version:** CLI đọc `.env.example`, agent/provider config, MCP config và routing files; phát hiện:
- credential được inject vào nhiều backend hơn scope khai báo,
- silent fallback sang provider khác,
- model/provider không hiển thị trước first call,
- write-capable MCP server không có explicit approval/read-only gate.

Có thể xuất JSON/SARIF để chạy trong GitHub Actions/Azure DevOps.

**Worth exploring now:** **Yes**, ở mức prototype 1–2 ngày. Đây là bài tập tốt về static config analysis + policy-as-code và gần với các workflow agent hiện tại.
