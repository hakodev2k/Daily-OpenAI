## 5. Tool I Can Apply Today

**Tool:** Git per-command hook isolation (`-c core.hooksPath=/dev/null`)  
**Problem it solves:** ngăn trusted host/runner vô tình thực thi repository-local hooks do untrusted code hoặc AI agent ghi vào worktree.  
**Relevant workflow:** AI coding agents, CI workers, ephemeral sandboxes, autonomous PR bots, repo automation.  
**Adoption difficulty:** Easy  
**Production readiness:** Production-ready Git capability; policy áp dụng vẫn cần test theo workflow cụ thể.

**Confirmed facts:** Git docs cho phép thay hook directory bằng `core.hooksPath`; current `git-config` docs nói rõ `/dev/null` có thể disable toàn bộ hooks và khuyến nghị dùng per-command qua `git -c core.hooksPath=/dev/null ...`. `git push --no-verify` bypass `pre-push`, nhưng `core.hooksPath=/dev/null` là guard tổng quát hơn khi muốn vô hiệu mọi local hook cho command đó.  
Docs: https://git-scm.com/docs/git-config/2.54.0.html  
Hooks: https://git-scm.com/docs/githooks

**Where it fits:** các automation nơi agent chỉnh source nhưng một host process khác giữ GitHub token, SSH key hoặc cloud credentials và chịu trách nhiệm commit/push.

**Integration approach:** centralize Git command construction trong một wrapper; với operations chạy trên untrusted worktree, inject per-command hook isolation thay vì dựa vào developer convention.

**Permissions/data access:** không cần quyền mới; đây là thay đổi cách gọi Git. Tuy nhiên host process vẫn cần existing Git credentials cho remote operation.

**Privacy/security concerns:** hook isolation không bảo vệ khỏi mọi attack path trong malicious repository. Cần tiếp tục kiểm soát executable files, Git config, submodules, credential helpers, environment injection và process execution boundaries.

**Maintenance burden:** thấp nếu đặt tại một Git transport abstraction thay vì thêm flags thủ công ở từng call site.

### Smallest proof of concept

Trong một disposable repository:

1. Tạo executable `.git/hooks/pre-push` ghi một marker file.
2. Chạy normal push tới local bare remote và xác nhận marker được tạo.
3. Xóa marker rồi chạy cùng push bằng `git -c core.hooksPath=/dev/null push ...`.
4. Xác nhận push vẫn chạy nhưng marker không được tạo.

Nếu POC đúng như Git docs, pattern này đáng đưa vào mọi automation nơi AI agent có write access vào worktree nhưng không được phép thực thi code trên trusted host.
