## 3. Bài đọc ngắn

### Đoạn đọc tiếng Anh

**Friday Release Plan**

The product team is preparing a small release for Friday. Tomorrow morning, Kevin is going to check the application logs at 8:30. At 9:00, Nora from QA is going to test the latest update in the test environment. The team is going to have a short review meeting at 9:40.

If the test result is good, the developers are going to deploy the update at 10:20. After deployment, Kevin is going to send a status update to the project manager. Nora is going to check the main user flow again, and the team is going to monitor the service until noon.

### Bản dịch tiếng Việt

Product team đang chuẩn bị một bản phát hành nhỏ cho thứ Sáu. Sáng mai, Kevin dự định kiểm tra application logs lúc 8:30. Lúc 9:00, Nora bên QA sẽ kiểm thử bản cập nhật mới nhất trong test environment. Nhóm sẽ có một cuộc họp review ngắn lúc 9:40.

Nếu kết quả test tốt, các developer sẽ deploy bản cập nhật lúc 10:20. Sau khi deploy, Kevin sẽ gửi status update cho project manager. Nora sẽ kiểm tra lại main user flow, và nhóm sẽ theo dõi service cho đến buổi trưa.

### Giải thích câu khó

#### `The product team is preparing a small release for Friday.`

- `is preparing` là Present Continuous vì đây là việc đang diễn ra ở thời điểm hiện tại.
- `for Friday` cho biết release được chuẩn bị cho thứ Sáu.

#### `Nora from QA is going to test the latest update in the test environment.`

Cấu trúc:

`Subject + be + going to + base verb`

- Subject: `Nora from QA`
- `be`: `is`
- base verb: `test`

Không dùng `is going to tested` hoặc `is going testing`.

#### `If the test result is good, the developers are going to deploy the update.`

- `if the test result is good` = nếu kết quả test tốt.
- `are going to deploy` = kế hoạch sẽ thực hiện nếu điều kiện phù hợp.
- Ở giai đoạn này chỉ cần hiểu ý nghĩa; chưa cần học sâu về conditional sentences.

#### `Nora is going to check the main user flow again.`

- `again` = lại / thêm một lần nữa.
- `check ... again` là cách nói rất thường gặp trong công việc khi verify sau deployment.

### Lỗi người Việt thường gặp

1. ❌ `Kevin going to check the logs.`  
   ✅ `Kevin is going to check the logs.`

2. ❌ `Nora is going to tested the update.`  
   ✅ `Nora is going to test the update.`

3. ❌ `When Kevin is going to send the update?`  
   ✅ `When is Kevin going to send the update?`

### Transcript

**Manager:** Eric, what is the plan for tomorrow morning?  
**Eric:** First, I’m going to check the application logs at eight forty.  
**Manager:** Who is going to test the update?  
**Eric:** Sarah from QA is going to test it at nine ten.  
**Manager:** What are you going to do after the test?  
**Eric:** We’re going to review the result in a short meeting.  
**Manager:** Are you going to deploy the update before ten?  
**Eric:** No, we aren’t. We’re going to deploy it at ten twenty-five if the test result is good.  
**Manager:** And after deployment?  
**Eric:** We’re going to monitor the service and send a status update.

### Bản dịch và điểm dễ nghe nhầm

- `What is the plan for tomorrow morning?` = Kế hoạch sáng mai là gì?
- `First, I’m going to check...` = Đầu tiên, tôi sẽ kiểm tra...
- `Who is going to test the update?` = Ai sẽ kiểm thử bản cập nhật?
- `after the test` = sau khi test.
- `before ten` = trước 10 giờ.
- `if the test result is good` = nếu kết quả test tốt.

### Điểm dễ nghe nhầm

1. `Who is going to...` có thể nối âm giữa `who is`.
2. `We’re going to` là dạng rút gọn của `We are going to`.
3. `eight forty` = 8:40; `nine ten` = 9:10; `ten twenty-five` = 10:25.
4. `aren’t` là phủ định; nếu bỏ sót âm này bạn có thể hiểu ngược ý.
5. `first`, `after`, `then` giúp xác định thứ tự công việc.

### Pronunciation focus

Shadow chậm, chú ý nhịp câu:

> First, I’m going to check the application logs.  
> Sarah is going to test the update.  
> We’re going to review the result.  
> We’re going to deploy it at ten twenty-five.  
> We’re going to monitor the service.

## 6. Ngữ pháp hôm nay

### Chủ điểm chính: Câu hỏi với `be going to`

### Cấu trúc

#### Câu hỏi Yes/No

`Am/Is/Are + subject + going to + base verb + ...?`

- `Are you going to deploy the update?`
- `Is Nora going to test the update?`

#### Câu hỏi Wh-

`Wh-word + am/is/are + subject + going to + base verb + ...?`

- `What are you going to do tomorrow?`
- `When is Kevin going to check the logs?`
- `Who is going to test the update?`

### Cách sử dụng

Dùng khi hỏi về một kế hoạch hoặc ý định tương lai đã có dự định.

So sánh:

- `What did Kevin do yesterday?` → hỏi việc đã hoàn thành trong quá khứ.
- `What is Kevin going to do tomorrow?` → hỏi kế hoạch tương lai.
- `What is Kevin doing now?` → hỏi việc đang diễn ra hiện tại.

### Ví dụ trong bài

- `Who is going to check the application logs?`
- `When is Nora going to test the latest update?`
- `What is the team going to do after deployment?`

### Lỗi người Việt thường gặp

1. ❌ `What Kevin is going to do tomorrow?`  
   ✅ `What is Kevin going to do tomorrow?`

2. ❌ `When is Nora going to tested the update?`  
   ✅ `When is Nora going to test the update?`

3. ❌ `Who are going to test the update?` khi chủ ngữ trả lời dự kiến là một người.  
   ✅ `Who is going to test the update?`

## 8. Bài tập chủ động

### Nhiệm vụ

Viết **4 câu tiếng Anh** về kế hoạch làm việc của bạn cho ngày mai.

Bắt buộc có:

1. Một câu với `I’m going to...`.
2. Một câu có thời gian cụ thể.
3. Một câu dùng một cụm từ hôm nay, ví dụ `check the application logs`, `review the test result`, `send a status update`.
4. Một câu hỏi với `What/When/Who ... going to...?`.

### Cấu trúc gợi ý

- `Tomorrow, I’m going to + base verb + ...`
- `At + time, I’m going to + base verb + ...`
- `After that, I’m going to + base verb + ...`
- `When are you going to + base verb + ...?`

### Ví dụ một câu

`Tomorrow, I’m going to review the application logs before the morning meeting.`

### Tiêu chí hoàn thành

- đủ 4 câu;
- dùng đúng `am/is/are`;
- sau `going to` dùng base verb;
- có ít nhất 2 cụm từ workplace;
- đọc to 4 câu một lần sau khi viết.
