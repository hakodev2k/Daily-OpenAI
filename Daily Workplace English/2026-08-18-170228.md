# Daily Workplace English — Ngày 4

- **Date in Vietnam time:** 18/08/2026
- **Workplace situation:** Requesting a focused code review for an ASP.NET Core API change
- **Main communication skill:** Yêu cầu code review rõ ràng, nêu đúng phạm vi và điều cần reviewer chú ý
- **Estimated study time:** 15–25 phút
- **Difficulty:** Elementary

## 1. Tình huống hôm nay

Bạn vừa hoàn thành một thay đổi cho ASP.NET Core API. Thay đổi này liên quan đến validation, Entity Framework Core query và một background job. Bạn cần nhờ một senior developer review pull request trước khi merge.

Nếu chỉ nhắn “Please review my PR” thì reviewer không biết phần nào quan trọng, thay đổi có rủi ro gì, và bạn cần feedback về vấn đề nào. Ngược lại, nếu giải thích quá dài, reviewer phải đọc nhiều thông tin không cần thiết trước khi bắt đầu review.

Mục tiêu hôm nay là yêu cầu code review theo một cấu trúc ngắn gọn: **context → scope → area of concern → requested action**.

## 2. Bạn cần nói gì?

Bạn cần truyền đạt các điểm sau:

- Nói ngắn gọn PR này thay đổi gì.
- Nêu phần quan trọng hoặc có rủi ro cần reviewer chú ý.
- Cho biết bạn đã test gì.
- Nếu cần, nói rõ loại feedback bạn muốn nhận.
- Đề nghị reviewer xem PR khi họ có thời gian, tránh cách nói giống ra lệnh.

## 3. Đoạn hội thoại hoặc mẫu trình bày

**Developer:** Hi Alex, could you take a look at my PR when you have a chance?

Chào Alex, khi có thời gian bạn có thể xem giúp PR của tôi được không?

**Reviewer:** Sure. What does it change?

Được. PR này thay đổi gì?

**Developer:** It updates the employee status API and moves the notification logic into the background job.

Nó cập nhật API thay đổi trạng thái employee và chuyển logic gửi notification vào background job.

**Developer:** The main thing I’d like you to check is whether the transaction handling is safe if the background job fails.

Điểm chính tôi muốn bạn kiểm tra là transaction handling có an toàn hay không nếu background job bị lỗi.

**Reviewer:** Have you tested the failure case?

Bạn đã test trường hợp lỗi chưa?

**Developer:** Yes. I’ve covered the normal flow and the failed-sync case with integration tests.

Có. Tôi đã cover normal flow và trường hợp sync thất bại bằng integration tests.

**Developer:** I’m also interested in any feedback on the EF Core query because it runs for every status update.

Tôi cũng muốn nhận feedback về EF Core query vì query này chạy mỗi lần status được cập nhật.

**Reviewer:** Got it. I’ll review it this afternoon.

Hiểu rồi. Tôi sẽ review vào chiều nay.

## 4. Các cụm từ quan trọng

### 1. “Could you take a look at my PR when you have a chance?”

- **Nghĩa:** Khi có thời gian, bạn có thể xem giúp PR của tôi không?
- **Khi dùng:** Yêu cầu review lịch sự trong chat hoặc trao đổi trực tiếp.
- **Ví dụ:** “Could you take a look at this API change when you have a chance?”

### 2. “It updates …”

- **Nghĩa:** Nó cập nhật/thay đổi …
- **Khi dùng:** Mô tả nhanh scope của PR.
- **Ví dụ:** “It updates the validation logic for inactive users.”

### 3. “The main thing I’d like you to check is …”

- **Nghĩa:** Điểm chính tôi muốn bạn kiểm tra là …
- **Khi dùng:** Hướng reviewer vào phần quan trọng nhất.
- **Ví dụ:** “The main thing I’d like you to check is the retry logic.”

### 4. “I’ve covered … with tests.”

- **Nghĩa:** Tôi đã cover … bằng test.
- **Khi dùng:** Cho reviewer biết phần nào đã được kiểm chứng.
- **Ví dụ:** “I’ve covered the edge cases with unit tests.”

### 5. “I’m also interested in any feedback on …”

- **Nghĩa:** Tôi cũng muốn nhận bất kỳ feedback nào về …
- **Khi dùng:** Khi muốn reviewer tập trung thêm vào design, query, naming hoặc performance.
- **Ví dụ:** “I’m also interested in any feedback on the API naming.”

### 6. “Let me know if anything is unclear.”

- **Nghĩa:** Hãy cho tôi biết nếu có gì chưa rõ.
- **Khi dùng:** Cuối message để reviewer có thể hỏi lại context.
- **Ví dụ:** “Let me know if anything is unclear in the migration script.”

## 5. Từ vựng trong tình huống

### review
- **Loại:** noun / verb
- **IPA:** /rɪˈvjuː/
- **Nghĩa:** xem xét, đánh giá
- **Ví dụ:** “Could you review this pull request?”
- **Collocation:** code review, review a PR

### scope
- **Loại:** noun
- **IPA:** /skoʊp/
- **Nghĩa:** phạm vi
- **Ví dụ:** “The scope of this PR is limited to the status update flow.”
- **Collocation:** project scope, PR scope

### transaction
- **Loại:** noun
- **IPA:** /trænˈzækʃən/
- **Nghĩa:** transaction, giao dịch dữ liệu
- **Ví dụ:** “Please check the transaction handling.”
- **Collocation:** database transaction, transaction handling

### failure case
- **Loại:** noun phrase
- **IPA:** /ˈfeɪljər keɪs/
- **Nghĩa:** trường hợp thất bại/lỗi
- **Ví dụ:** “I added a test for the failure case.”
- **Collocation:** handle a failure case, test a failure case

### integration test
- **Loại:** noun phrase
- **IPA:** /ˌɪntɪˈɡreɪʃən test/
- **Nghĩa:** kiểm thử tích hợp
- **Ví dụ:** “The integration test covers the background job flow.”
- **Collocation:** run integration tests, integration test suite

### feedback
- **Loại:** noun
- **IPA:** /ˈfiːdbæk/
- **Nghĩa:** phản hồi
- **Ví dụ:** “I’d appreciate feedback on the query.”
- **Collocation:** give feedback, receive feedback

## 6. Mẫu câu hoặc ngữ pháp cần nhớ

### Present perfect để nói phần việc đã hoàn thành trước thời điểm review

Cấu trúc:

**have/has + past participle**

Ví dụ:

- “I’ve covered the normal flow with integration tests.”
- “I’ve added validation for the missing employee case.”
- “I’ve tested the failed-sync scenario.”

Dùng present perfect khi bạn muốn nhấn mạnh kết quả hiện tại: những test hoặc thay đổi đó đã có trong PR và reviewer có thể kiểm tra ngay bây giờ.

So sánh:

- “I added two tests yesterday.” → nhấn vào thời điểm quá khứ.
- “I’ve added two tests.” → nhấn vào trạng thái hiện tại của PR.

**Lỗi thường gặp:** “I have tested it yesterday.”

Nếu có thời điểm cụ thể như `yesterday`, dùng past simple:

**“I tested it yesterday.”**

## 7. Cách nói tự nhiên hơn

### Chưa tự nhiên hoặc quá trực tiếp

“Review my PR.”

### Tự nhiên và chuyên nghiệp hơn

“Could you take a look at my PR when you have a chance?”

### Giải thích

Câu đầu nghe giống mệnh lệnh. Câu thứ hai vẫn rõ ràng nhưng phù hợp hơn khi yêu cầu một đồng nghiệp dành thời gian review.

### Chưa tự nhiên hoặc quá chung chung

“Please check everything.”

### Tự nhiên và chuyên nghiệp hơn

“The main thing I’d like you to check is the transaction handling.”

### Giải thích

Reviewer luôn có thể review toàn bộ PR, nhưng việc nêu một area quan trọng giúp họ ưu tiên attention đúng chỗ.

### Chưa tự nhiên

“I want your comments about the query.”

### Tự nhiên và chuyên nghiệp hơn

“I’m also interested in any feedback on the EF Core query.”

### Giải thích

`feedback on` tự nhiên hơn `comments about` trong tình huống xin nhận xét kỹ thuật. Tuy nhiên, trong một review comment cụ thể, từ `comment` vẫn hoàn toàn phù hợp.

## 8. Phát âm và luyện nói

### “Could you take a look at my PR?”

- Nhấn vào **TAKE**, **LOOK**, **PR**.
- `Could you` thường được nói nhẹ và nối với nhau.
- Có thể ngắt: “Could you take a look / at my PR?”
- Không cần cố đọc `could` quá mạnh.

### “The main thing I’d like you to check is …”

- Nhấn **MAIN**, **CHECK**, và từ khóa sau `is`.
- `I’d` là dạng rút gọn của `I would`.
- Có thể ngắt: “The main thing I’d like you to check / is the transaction handling.”

### “I’ve covered the normal flow with tests.”

- Nhấn **COVERED**, **NORMAL FLOW**, **TESTS**.
- `I’ve` nên được nói liền, không tách thành `I have` nếu đang luyện spoken English tự nhiên.

### Shadowing script

> Could you take a look at my PR when you have a chance?  
> It updates the employee status API and the background job flow.  
> The main thing I’d like you to check is the transaction handling.  
> I’ve covered the normal flow and the failure case with integration tests.

Luyện theo thứ tự:

1. Đọc chậm.
2. Nghe bằng Text-to-Speech nếu có.
3. Lặp từng câu.
4. Ghi âm giọng của bạn.
5. Nói lại cả đoạn mà không nhìn text.

## 10. Bài tập thực hành chủ động

### Scenario

Bạn vừa mở một PR thay đổi endpoint `GET /employees`. PR thêm filter theo status, đổi một EF Core query và thêm pagination. Bạn đã test normal case và empty result, nhưng muốn reviewer đặc biệt kiểm tra query performance và cách pagination được xử lý.

### Required points

Viết một message 5–6 câu bằng tiếng Anh, bao gồm:

- Lời nhờ review lịch sự.
- Scope chính của PR.
- Phần cần reviewer chú ý nhất.
- Những test bạn đã thực hiện.
- Một câu mở để nhận thêm feedback.

### Suggested structure

1. “Could you take a look at …?”
2. “It updates …”
3. “The main thing I’d like you to check is …”
4. “I’ve covered … with tests.”
5. “I’m also interested in any feedback on …”

### Completion criteria

Message hoàn thành khi reviewer có thể hiểu trong khoảng 20–30 giây: **PR thay đổi gì, cần chú ý gì, và phần nào đã được test**.

## 11. Đáp án và giải thích

---

**Hãy hoàn thành bài tập trước khi xem đáp án.**

---

### Bài 1

**Đáp án: B — look**

Cụm tự nhiên là **“take a look at …”**.

### Bài 2

**Đáp án: B**

Câu B rõ ràng và lịch sự. A và C nghe giống mệnh lệnh nếu không có context khẩn cấp.

### Bài 3

**Đáp án: check**

Câu đầy đủ: **“The main thing I’d like you to check is the retry logic.”**

### Bài 4

**Đáp án: A — have covered**

Present perfect phù hợp vì bạn đang nói về trạng thái hiện tại của PR. Nếu muốn dùng `yesterday`, phải nói: **“I covered the normal flow yesterday.”**

### Bài 5

Một đáp án tốt:

**“The main thing I’d like you to check is whether the EF Core query could cause any performance issues.”**

Một lựa chọn khác ngắn hơn:

**“Could you pay particular attention to the EF Core query performance?”**

## 12. Mẫu trả lời tham khảo

**“Hi Alex, could you take a look at my PR when you have a chance? It adds status filtering and pagination to the employee endpoint. The main thing I’d like you to check is the EF Core query performance, especially with pagination. I’ve covered the normal flow and the empty-result case with integration tests. I’m also interested in any feedback on the pagination logic. Let me know if anything is unclear.”**

Các pattern có thể tái sử dụng:

- **“Could you take a look at …?”**
- **“The main thing I’d like you to check is …”**
- **“I’ve covered … with tests.”**
- **“I’m also interested in any feedback on …”**

## 13. Thử nói lại theo cách của bạn

Lấy một PR hoặc change thật mà bạn đang làm và điền template sau:

- **Context:** This PR changes …
- **Scope:** It updates …
- **Main review area:** The main thing I’d like you to check is …
- **Testing:** I’ve tested …
- **Additional feedback:** I’m also interested in feedback on …
- **Closing:** Let me know if anything is unclear.

Sau đó nói lại thành một đoạn 45–60 giây mà không đọc từng dòng.

## 14. Tóm tắt cần ghi nhớ

### 3 câu nên nhớ

1. **“Could you take a look at my PR when you have a chance?”**
2. **“The main thing I’d like you to check is …”**
3. **“I’ve covered the normal flow and the failure case with tests.”**

### Lỗi cần tránh

- Chỉ nói “Review my PR” mà không có context.
- Không nói phần nào cần reviewer chú ý nếu PR có một area rủi ro rõ ràng.
- Không dùng present perfect cùng `yesterday`: tránh “I have tested it yesterday.”

### Thử thách hôm nay

Chọn một PR thật của bạn và viết một code-review request chỉ **4–6 câu** theo cấu trúc: **scope → risk → tests → requested feedback**. Sau đó đọc message đó thành tiếng một lần trước khi gửi.
