# Daily Workplace English — Ngày 18

- Date in Vietnam time: 2026-08-18
- Workplace situation: Giải thích nguyên nhân dự kiến của một bug production
- Main communication skill: Mô tả root cause và kế hoạch xử lý
- Estimated study time: 15–25 phút
- Difficulty: Lower-intermediate

## 1. Tình huống hôm nay

Một API .NET đang chạy production có vấn đề: một số request bị timeout khi tải dữ liệu lớn. Product Owner và QA muốn biết nguyên nhân. Bạn chưa có kết luận cuối cùng nhưng đã thấy dấu hiệu liên quan đến database query và thiếu pagination.

Bạn cần giải thích tình hình một cách chuyên nghiệp: không đổ lỗi cho database, không khẳng định nguyên nhân khi chưa chắc chắn, đồng thời đưa ra bước điều tra tiếp theo.

## 2. Bạn cần nói gì?

- Xác nhận bạn đã hiểu vấn đề.
- Mô tả những gì đã kiểm tra.
- Phân biệt fact và assumption.
- Giải thích hướng điều tra tiếp theo.
- Cam kết thời điểm cập nhật thông tin mới.

## 3. Đoạn hội thoại

**QA:** The API is timing out when loading a large amount of data. Have you found the root cause yet?

API đang timeout khi tải lượng dữ liệu lớn. Bạn đã tìm ra nguyên nhân gốc chưa?

**Developer:** I have investigated the issue, but I haven't confirmed the root cause yet.

Tôi đã điều tra vấn đề, nhưng tôi chưa xác nhận được nguyên nhân gốc.

**Developer:** Based on the current logs, it looks like the database query is taking longer than expected.

Dựa trên log hiện tại, có vẻ query database mất nhiều thời gian hơn dự kiến.

**QA:** What will you check next?

Bạn sẽ kiểm tra gì tiếp theo?

**Developer:** I will review the query performance and check whether we need pagination or additional indexes.

Tôi sẽ kiểm tra performance của query và xem có cần pagination hoặc index bổ sung không.

**Developer:** I will update everyone once I have more evidence.

Tôi sẽ cập nhật cho mọi người khi có thêm bằng chứng.

## 4. Các cụm từ quan trọng

### “I haven't confirmed the root cause yet.”
- Nghĩa: Tôi chưa xác nhận nguyên nhân gốc.
- Dùng khi chưa đủ bằng chứng.
- Ví dụ: I haven't confirmed the cause of the deployment failure yet.

### “Based on the current logs, it looks like...”
- Nghĩa: Dựa trên log hiện tại, có vẻ...
- Dùng để đưa ra nhận định chưa chắc chắn.
- Ví dụ: Based on the metrics, it looks like memory usage is increasing.

### “I need more evidence before making a conclusion.”
- Nghĩa: Tôi cần thêm bằng chứng trước khi kết luận.
- Dùng trong debugging.
- Ví dụ: I need more evidence before changing the architecture.

### “I will investigate this further.”
- Nghĩa: Tôi sẽ điều tra thêm.
- Dùng để xác nhận action tiếp theo.
- Ví dụ: I will investigate this further and share an update tomorrow.

### “The current assumption is that...”
- Nghĩa: Giả định hiện tại là...
- Dùng khi nói về hypothesis.
- Ví dụ: The current assumption is that the cache is expired too frequently.

## 5. Từ vựng trong tình huống

- Root cause (noun) /ruːt kɔːz/: nguyên nhân gốc. Collocation: identify the root cause.
- Investigate (verb) /ɪnˈvestɪɡeɪt/: điều tra. Collocation: investigate an issue.
- Evidence (noun) /ˈevɪdəns/: bằng chứng. Collocation: collect evidence.
- Assumption (noun) /əˈsʌmpʃən/: giả định. Collocation: make an assumption.
- Timeout (noun) /ˈtaɪmaʊt/: hết thời gian chờ. Collocation: request timeout.

## 6. Mẫu câu cần nhớ

Pattern: **It looks like + clause**

Dùng để nói một nhận định chưa chắc chắn.

Ví dụ:
- It looks like the API response time is increasing.
- It looks like the issue happens only with large requests.

Lỗi thường gặp: Không nên dùng “It is” khi bạn chưa chắc chắn.

## 7. Cách nói tự nhiên hơn

### Chưa tự nhiên
“The database is slow.”

### Tự nhiên hơn
“The current evidence suggests that the database query may be causing the delay.”

### Giải thích
Câu thứ hai tránh kết luận quá sớm và phù hợp trong môi trường chuyên nghiệp.

### Chưa tự nhiên
“I don't know the problem.”

### Tự nhiên hơn
“I haven't identified the root cause yet, but I am investigating it.”

### Chưa tự nhiên
“Fix this bug now.”

### Tự nhiên hơn
“I will work on the fix and provide an update once I have more information.”

## 8. Phát âm và luyện nói

Cụm quan trọng:

- root cause: nhấn ROOT CAUSE.
- investigate the issue: nhấn INVESTIGATE.
- based on the current logs: nối âm based_on.

Shadowing:

“I haven't confirmed the root cause yet. Based on the current logs, it looks like the query performance is the main concern. I will investigate this further and provide an update.”

## 9. Bài tập nhanh

1. Điền từ: “I haven't ___ the root cause yet.”
2. Chọn câu chuyên nghiệp hơn: “The code is bad” hay “The current implementation may need optimization.”
3. Viết lại: “Tell me the problem.”
4. Hoàn thành: “Based on the logs, it looks like ____.”

## 10. Bài tập thực hành chủ động

Scenario: Một background job trong .NET chạy chậm hơn bình thường.

Hãy nói 5–6 câu bằng tiếng Anh:
- Vấn đề là gì.
- Bạn đã kiểm tra gì.
- Điều gì bạn chưa chắc chắn.
- Bạn sẽ làm gì tiếp theo.
- Khi nào cập nhật lại.

Dùng các cụm:
“I haven't confirmed...”, “Based on...”, “I will investigate...”

## 11. Đáp án và giải thích

---

**Hãy hoàn thành bài tập trước khi xem đáp án.**

1. confirmed. Vì cần động từ sau haven't.
2. “The current implementation may need optimization.” vì tránh phán xét.
3. “Could you provide more details about the issue?” lịch sự hơn.
4. Ví dụ: “Based on the logs, it looks like the query is taking too long.”

## 12. Mẫu trả lời tham khảo

“The background job is running slower than expected. I have checked the application logs and database metrics. I haven't confirmed the root cause yet, but the current assumption is that one query needs optimization. I will investigate this further and update the team after reviewing the execution plan.”

## 13. Thử nói lại theo cách của bạn

Template:
- Context:
- What happened:
- What I checked:
- Current assumption:
- Next action:
- Expected update:

Hãy thay bằng một bug hoặc task thật trong công việc .NET của bạn.

## 14. Tóm tắt cần ghi nhớ

### 3 câu nên nhớ

1. I haven't confirmed the root cause yet.
2. Based on the current logs, it looks like...
3. I will investigate this further and provide an update.

### Lỗi cần tránh

- Kết luận nguyên nhân khi chưa có evidence.
- Dùng “I don't know” thay vì mô tả trạng thái điều tra.
- Dùng câu quá trực tiếp khi trao đổi incident.

### Thử thách hôm nay

Ghi âm một đoạn 1 phút giải thích một bug hoặc issue đang gặp bằng cấu trúc: Problem → Evidence → Assumption → Next action.
