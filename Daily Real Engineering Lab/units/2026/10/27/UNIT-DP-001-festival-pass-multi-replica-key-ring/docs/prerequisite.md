# Trước lab

Cần biết C# và lệnh `dotnet run`. Token của ASP.NET Core Data Protection không phải JWT; đây là cơ chế authenticated encryption dựa trên provider, protector và purpose. Chưa cần biết chi tiết key-ring implementation trước khi reproduce.

Dùng PowerShell tại thư mục unit, không cần quyền administrator. Không dùng token thật hay production key trong lab.
