# Tài liệu tham khảo (sau lab)

- PostgreSQL — [Logical Replication Concepts](https://www.postgresql.org/docs/current/logical-replication.html): replication slot, publication và thứ tự thay đổi.
- Elasticsearch — [Aliases](https://www.elastic.co/guide/en/elasticsearch/reference/current/aliases.html): read alias và cập nhật alias.
- Elasticsearch — [Reindex API](https://www.elastic.co/guide/en/elasticsearch/reference/current/docs-reindex.html): dữ liệu nguồn, versioning và giới hạn reindex.
- Elasticsearch — [Index modules / settings](https://www.elastic.co/guide/en/elasticsearch/reference/current/index-modules.html): tài nguyên và vận hành index.

Các tài liệu giúp đối chiếu API production. Bài lab dùng synthetic evidence và không yêu cầu truy cập dịch vụ ngoài.
