# Prerequisites
- GET lấy representation và metadata; PUT yêu cầu thay representation.
- Status 2xx nghĩa server chấp nhận request theo contract mà nó thực thi.
- C# lock bảo vệ critical section trong một process, không thay thế database transaction.
- Harness mô phỏng HTTP boundary; không phải web server hay integration test thật.
