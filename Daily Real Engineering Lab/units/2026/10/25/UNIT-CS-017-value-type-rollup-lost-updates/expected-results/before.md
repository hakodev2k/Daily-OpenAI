# Trước khi sửa
- `./run.ps1` log 4 sự kiện được nhận.
- Dashboard của `TECH-17` và `TECH-42` đều có tổng 0 dù input không rỗng.
- `./reproduce.ps1` trả exit code 0 và in `REPRODUCED`.
- `./verify.ps1` trả exit code khác 0 do các assertion tổng hợp thất bại.
- Nếu không thấy triệu chứng, xác nhận chưa sửa starter và chạy đúng project trong `starter/`.
