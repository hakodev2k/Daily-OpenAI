# Reference solution — chỉ đọc sau khi tự điều tra

Chạy `dotnet run --project solution/WebhookLab.csproj`. Expected: `ACCEPT`, `DUPLICATE`, `REJECT stale`, `ACCEPT`, `Applied=2`. Bản tham khảo dùng clock cố định để chứng minh chính sách thời gian, `FixedTimeEquals` và `HashSet` cho demo single-process. Trong production, thay HashSet bằng unique constraint hoặc conditional insert bền vững theo `(provider, deliveryId)`; thực hiện claim và business write trong một transaction hoặc inbox/outbox có recovery. TTL của khóa dedupe phải lớn hơn retry horizon của provider; kiểm soát clock skew, signature key rotation, raw body canonicalization, forged delivery ID, và crash giữa claim/side effect. Nếu payload có event ID độc lập, cân nhắc dedupe theo business event thay vì chỉ HTTP delivery. Không ghi secret hoặc full payload nhạy cảm vào logs. Đo duplicate rate, rejected age và backlog; ACK retry có chủ đích theo contract.
