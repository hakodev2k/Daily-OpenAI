# Investigation worksheet

Ghi lại 3 URI thực tế và expected. Giả thuyết A: credential mismatch; B: gateway prefix routing; C: DNS mismatch. Chọn evidence có thể bác bỏ từng giả thuyết. Chạy reproduction trước khi chỉnh code. Sau verify, bổ sung case `relativeRoute` có slash đầu và base path không có slash cuối; mô tả policy mong muốn. Không log query chứa dữ liệu nhạy cảm.
