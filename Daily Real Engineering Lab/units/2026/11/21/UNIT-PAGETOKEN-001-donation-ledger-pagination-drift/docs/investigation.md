# Investigation
Lập bảng thứ tự ID trước/sau insert; thử đối chứng không insert. Đề xuất query với total order và cursor; kiểm tra insert đồng timestamp, update/delete, cursor giả mạo, thay đổi filter. Phân biệt live traversal và immutable audit snapshot. Acceptance: không lặp ID trong append-only case, giải thích giới hạn consistency và có phép thử xác nhận.
