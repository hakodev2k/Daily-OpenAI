# Before — Starter
Sau `./reproduce.ps1`, Git chỉ tracked một policy trong revision mới. Artifact có thêm ít nhất hai file ngoài Git tracked set. Script kiểm tra in `REPRODUCED` và trả thành công vì **lỗi đã được chứng minh**. Nếu không reproduce được, chạy lại setup; bảo đảm Git và PowerShell có trong PATH.
