# Prerequisites

- Desired state vs observed state; idempotency, optimistic concurrency và at-least-once delivery.
- Canary, blast radius, RTO, rollback, safety invariant, fault injection.
- Đổi MiB sang GiB; phân biệt throughput lý thuyết với SLO cam kết.
- Đọc CSV và viết ADR. Không cần biết trước sản phẩm Azure cụ thể.
