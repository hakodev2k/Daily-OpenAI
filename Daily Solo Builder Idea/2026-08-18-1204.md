# Ý tưởng hôm nay: Personal Infrastructure Cost Tracker

## 1. Tóm tắt ý tưởng

Một công cụ cá nhân giúp developer theo dõi chi phí hạ tầng cloud, VPS, domain, API và các subscription kỹ thuật đang sử dụng. Sản phẩm tự động tổng hợp chi phí, phát hiện dịch vụ ít dùng và đưa ra cảnh báo tối ưu hóa.

- Người dùng: solo developer, freelancer, indie hacker.
- Quy mô: Small đến Medium.
- MVP: 2–3 tuần.

## 2. Bài toán thực tế

Developer thường có nhiều tài khoản dịch vụ như Azure, AWS, GitHub, OpenAI API, VPS, domain, database hosting và các công cụ SaaS.

Vấn đề thường gặp:

- Quên các subscription đang trả phí.
- Không biết service nào đang tăng chi phí.
- Khó tổng hợp chi phí dự án cá nhân.

Giả định: với người xây nhiều project nhỏ, việc nhìn thấy tổng chi phí vận hành giúp quyết định giữ hoặc loại bỏ dịch vụ dễ hơn.

## 3. Người dùng mục tiêu

Primary user:

- Developer xây side project hoặc làm freelance.

Pain point:

- Chi phí nhỏ nhưng cộng dồn.
- Không có dashboard riêng cho toàn bộ tài nguyên cá nhân.

Workaround:

- Kiểm tra từng portal.
- Lưu thủ công vào spreadsheet.

## 4. Giải pháp đề xuất

Ứng dụng cho phép nhập các nguồn chi phí và tự động tổng hợp.

Workflow:

1. Người dùng kết nối cloud provider hoặc nhập dữ liệu CSV.
2. Hệ thống chuẩn hóa cost record.
3. Phân nhóm theo project/service.
4. Hiển thị dashboard.
5. Gửi cảnh báo khi vượt ngân sách.

Ví dụ:

Developer phát hiện Azure App Service test environment đã chạy 3 tháng không sử dụng và nhận cảnh báo nên xóa hoặc scale down.

Điểm khác biệt: tập trung vào developer cá nhân thay vì FinOps enterprise.

## 5. Tại sao ý tưởng này đáng làm

Giá trị:

- Có thể dùng ngay cho chính các project cá nhân.
- Học kỹ năng cloud cost management.

Kỹ thuật:

- API integration.
- Data normalization.
- Background jobs.
- Reporting.

Có thể thất bại nếu người dùng không đủ nhiều dịch vụ để cần quản lý.

## 6. Phạm vi MVP

### Must have

- CRUD project.
- Import cost CSV.
- Dashboard chi phí theo tháng.
- Budget alert.

### Should have

- Azure cost integration.
- Email/Telegram notification.
- Cost trend chart.

### Later

- AI phân tích tối ưu.
- Multi-account support.
- Team sharing.

## 7. Luồng hoạt động

User nhập project
→ upload cost data
→ validate
→ normalize
→ lưu database
→ tính toán tổng chi phí
→ hiển thị dashboard
→ gửi cảnh báo.

Failure:

- File sai format.
- API provider unavailable.
- Currency conversion lỗi.

## 8. Kiến trúc đề xuất

Modular monolith:

- Frontend: Vue 3.
- Backend: ASP.NET Core Web API.
- Database: PostgreSQL.
- Worker: BackgroundService cho sync và alert.
- Storage: Blob storage nếu cần lưu file.
- Notification: Telegram bot.
- Logging: Serilog.

Không cần microservice.

## 9. Công nghệ đề xuất

- .NET 10 + ASP.NET Core: phù hợp backend.
- EF Core + PostgreSQL: quản lý dữ liệu linh hoạt.
- Hangfire/BackgroundService: chạy đồng bộ định kỳ.
- Vue 3: dashboard nhanh.
- Docker: deploy dễ.
- GitHub Actions: CI/CD.

Alternative: SQLite + Blazor nếu chỉ dùng cá nhân.

## 11. API và tích hợp

Azure Cost Management API:

- Mục đích: lấy dữ liệu chi phí Azure.
- Authentication: Azure credential.
- Concern: permission và billing access.
- Fallback: CSV export.

GitHub API:

- Mục đích: quản lý subscription liên quan developer.
- Concern: token permission.

## 12. AI có thực sự cần thiết không?

AI useful but optional.

Có thể dùng AI để:

- Giải thích nguyên nhân tăng chi phí.
- Đề xuất hành động tối ưu.

Không dùng AI cho tính toán cost.

Risk:

- Chi phí API.
- Gợi ý sai.

## 20. Việc cần làm ngay hôm nay

Mục tiêu 60–120 phút: tạo backend MVP lưu và tổng hợp cost record.

Tasks:

```bash
dotnet new webapi -n CostTracker.Api
```

Tạo:

```
/Entities
/Services
/Controllers
/Data
```

Implement:

- Project entity.
- CostRecord entity.
- POST /cost-records.
- GET /projects/{id}/summary.

Verification:

- Tạo project.
- Import 10 cost records.
- Nhận tổng chi phí theo tháng.

Stop condition:

API trả về dashboard summary đầu tiên chạy được end-to-end.
