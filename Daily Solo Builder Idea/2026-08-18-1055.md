# Ý tưởng hôm nay: Dev Context Vault - Kho lưu trữ ngữ cảnh phát triển cá nhân

## 1. Tóm tắt ý tưởng
Dev Context Vault là công cụ giúp developer lưu trữ và tái sử dụng context của dự án như architecture decision, coding rules, bug history, API notes và AI instructions. Người dùng chính là senior developer, tech lead hoặc solo builder. Quy mô Medium, MVP khoảng 2-3 tuần.

## 2. Bài toán thực tế
Developer thường mất thời gian tìm lại lý do của các quyết định kỹ thuật, cấu trúc hệ thống, lỗi đã xử lý hoặc thông tin cần cung cấp cho AI coding agent. Hiện nay thông tin thường nằm rải rác trong README, wiki, chat, issue hoặc file cá nhân.

Đây là giả định cần được validate bằng việc dùng thử trong workflow thực tế.

## 3. Người dùng mục tiêu
Senior backend developer và solo builder quản lý nhiều repository.

Pain point: mất context khi quay lại dự án sau thời gian dài hoặc khi chuyển đổi giữa nhiều task.

## 4. Giải pháp đề xuất
Xây dựng một kho context có cấu trúc cho từng project.

Workflow:
- Tạo project context.
- Import markdown, ADR, API docs.
- Gắn tag và phân loại.
- Export context bundle cho AI assistant hoặc developer khác.

Điểm khác biệt là tập trung vào context engineering thay vì chỉ lưu note.

## 5. Tại sao đáng làm
Có giá trị ngay cho chính developer sử dụng hàng ngày. Dự án phù hợp với kỹ năng .NET, database, AI workflow và có thể mở rộng thành MCP server hoặc developer tool.

Rủi ro lớn nhất là người dùng không duy trì context. Vì vậy MVP phải cực kỳ đơn giản.

## 6. Phạm vi MVP

### Must have
- Project management.
- Markdown/text context storage.
- Search.
- Export context bundle.

### Should have
- Git repository sync.
- Version history.
- AI summary.

### Later
- VS Code extension.
- MCP integration.
- Team collaboration.

## 7. Luồng hoạt động
User tạo project → nhập context → validate → lưu database/file storage → tìm kiếm → export bundle → sử dụng khi code.

Failure case: file lỗi format, duplicate content, context quá lớn cần giới hạn export.

## 8. Kiến trúc đề xuất
Modular monolith:
- ASP.NET Core API.
- Vue frontend.
- PostgreSQL + EF Core.
- Background worker cho indexing.
- Object storage cho tài liệu.

Không cần microservice trong MVP.

## 9. Công nghệ đề xuất
- .NET 10 + ASP.NET Core.
- EF Core + PostgreSQL.
- Vue 3.
- Docker Compose.
- GitHub Actions.

Alternative đơn giản: SQLite cho cá nhân.

## 10. Thiết kế dữ liệu ban đầu
Project: Id, Name, RepositoryUrl, CreatedAt.

ContextDocument: Id, ProjectId, Title, Content, Type, Hash.

ContextTag: Id, Name.

## 11. API và tích hợp
Có thể tích hợp GitHub API để lấy repository metadata. AI API chỉ dùng cho summary hoặc extraction.

Fallback: hoạt động hoàn toàn với local files.

## 12. AI có thực sự cần thiết không?
AI useful but optional.

AI dùng cho:
- Tóm tắt tài liệu.
- Tạo context package.
- Trích xuất decision.

Rule: AI output phải validate bằng schema, luôn có fallback deterministic.

## 13. Kế hoạch triển khai

### Phase 0
Dùng prototype markdown trong một repository cá nhân để xác định loại context cần lưu.

### Phase 1
Build CRUD context, search và export bundle.

### Phase 2
Thêm authentication, backup, logging, tests.

### Phase 3
Thêm Git sync, AI summary, semantic search.

### Phase 4
Deploy cloud/self-hosted, monitoring, documentation.

## 14. Các bài toán kỹ thuật đáng học
- Search và indexing.
- Document versioning.
- AI structured output validation.
- Git synchronization.

## 15. Rủi ro và cách xử lý
- Scope lớn: giới hạn MVP vào markdown context.
- Privacy: hỗ trợ self-hosted.
- AI cost: chỉ gọi khi cần.
- Adoption: sử dụng cho chính dự án cá nhân trước.

## 16. Kiểm thử
1. Import context thành công.
2. Search trả đúng tài liệu.
3. Duplicate detection hoạt động.
4. Export bundle chính xác.
5. Permission bảo vệ dữ liệu.

## 17. Cách đo dự án hữu ích
- Số lần context được sử dụng.
- Thời gian tìm thông tin giảm.
- Số project quản lý.
- Tỷ lệ export thành công.

## 18. Khả năng mở rộng
- MCP server cho AI agent.
- VS Code extension.
- Team knowledge platform.
- Open-source developer memory system.

## 19. Mô hình giá trị
Phù hợp với:
- Personal utility.
- Portfolio project.
- Open-source tool.
- SaaS cho team nhỏ.

## 20. Việc cần làm ngay hôm nay
Trong 60-120 phút:
1. Tạo ASP.NET Core solution.
2. Tạo entity Project và ContextDocument.
3. Kết nối PostgreSQL.
4. Tạo API tạo project.
5. Tạo API lưu context.
6. Tạo endpoint export markdown bundle.

Kết quả: có workflow hoàn chỉnh từ tạo project đến xuất context có thể dùng cho AI assistant.
